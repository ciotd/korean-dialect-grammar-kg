# 50문장: 필요한 정보가 끊긴 지점과 해결안

[읽기 쉬운 전체 대조표](http://127.0.0.1:8767/reports/bottleneck-audit-20261030/report.html)

## 목적과 완료 범위

사용자는 승인한 Claude 표현과 실제 처리 기록을 대조해, 문제 위치뿐 아니라 구체적 해결책까지 제시하도록 요청했다. 최신 `20261030T062819598143Z_scoped`의 Single/Multi 100개 실행 기록과 승인 참조50개를 대조했다. 각 입력별 관찰·수정 제안·미확정 범위를 `private/notes.json`에 작성했다. 실제 원문 분석 값에 관한 구체적 검토 의견17건을 별도로 기록했다. 이는 분석 오류율 측정이나 전체 해석의 정답 인증이 아니다.

새 모델 호출, 신규 KG 조회, 생성 코드 변경, 카드 변경은 없다. 보고서 제공을 위한 기존 대시보드 경로만 추가했다. 원본 결과·입력·참조·카드를 덮어쓰지 않았다. 모든 연구 수정안은 제안 상태다.

## 핵심 판단

- 분석 단계에 반말/높임·부정·진행·질문 종류 오류가 있다. 예: LONG001 반말 전체 formal, DEV012 부정이 없는데 negation.
- 카드가 있다는 사실은 직접 적용 가능한 지식이 있다는 뜻이 아니다. 묵-의 무우 활용과 먹다→묵다는 다른 지식이다. 형태 목록과 표준어 입력→방언 출력의 대응을 구분한다.
- 실제 조회와 최종 전달을 구분했다. 옇다는 조회 전, -다·쪼매·일부 요청형·의도형은 조회 후 선별 단계에서 누락된 기록이 있다. 이 사실만으로 후보를 추가하면 성공한다고 결론내리지 않는다.
- 생성 계약은 어휘 보존·어미/조사 편집 중심이다. 승인 참조의 어휘·구문 변화 전체를 현재 계약으로 처리하기 어렵다.
- 검사에는 과소 차단과 과잉 차단이 모두 있다. 금지에 약속 카드를 적용한 LONG004는 기능 검사 누락, 승인된 계십니더를 막은 ADVCE002A는 재분석 기반 보류다. NEW004의 파생동사 거절과 DEV011의 계사 카드 거절도 구분한다.
- 실패10개 실행은 분석2·번호3·길이3·편집 계약2로 분리된다. 설명 반복은 짧은 입력에서도 발생하므로 긴 문장 탓으로만 해석하지 않는다.
- 성공한 부분도 보존한다. 라예·어예 등 부분 성공을 어휘 차이 때문에 통째로 실패 처리하지 않는다.

## 제안 순서와 검증

1. 분석 출력/기능 목록/개념 연결의 일관성과 응답·편집 계약부터 정리한다.
2. 필요한 말단 지식을 입력·조건·교체 범위·목표 구성으로 연결한다. 기존 척추·모듈을 전면 재구축하지 않는다.
3. 위치별 후보 선택과 공통 교체 동작·보존 검사를 연결한다. 금지/약속 등의 충돌을 막는 것과 맞는 대안 선택을 함께 다룬다.
4. 이후 같은50개에서 분석만/선택만/조합만 바꾼 비교를 설계한다. 이번 감사에서는 새로운 인과 확인 실험을 수행하지 않았다.

구체적 코드 위치·변경 내용·통과/거절 테스트는 `private/solutions.json` 및 HTML에 있다. 이 순서는 가장 큰 효과를 이미 입증한 순위가 아니라, 앞단 오류가 뒤쪽 판단을 흐리지 않게 하는 의존 순서다.

## 재현 및 근거

- `gather.py`: 최신 동결 실행과 이전 문헌 비교의 후보 목록을 결합한다. 실제 전달 packet을 기준으로 판정하며 과거 selection_audit의 selected 값을 최종 전달로 오인하지 않는다.
- `inspect_cases.py START END`: 50개 기록의 읽기 전용 요약 확인용.
- `report.py`: 자료 불변 해시·참조 동일성·50개 검토 완전성을 검사하고 보고서·통계를 재생성한다.
- `private/evidence.json`: 원문/승인 표현, 실제 분석·조회·전달 카드·원래 모델 응답·최종 계획·출력. 각 실행 원본 경로 포함.
- `private/notes.json`: 총괄이 작성한 입력별50개 판단과 해결안. 기계 집계와 구별한다.
- `private/analysis_observations.json`: 실제 분석 값과 비교한17개 구체적 검토 의견.
- `private/solutions.json`: 공통 원인별 수정 위치·방법·검증·한계.
- `private/input_hashes.json`, `verification.json`: 읽은 원본의 SHA-256과 재생성 시 검증.
- `private/summary.json`: 중단 오류·후보 경로·중복 가능한 검토 주제 집계. 원인별 실패율/정확도 아님.

원본 문헌 전체를 이번에 재정독하지 않았다. 기존 `claude_comparison_20261030`의 문헌 대조 위치·인용 근거를 재사용했고 현재 카드 본문을 확인했다. 관련 후보 매핑은 전체 가능한 표현의 완전성 증명이 아니다. 후보 존재·조회·전달·선택·반영과 실제 적용 가능성을 구별한다. 어휘 문자 검색 실패를 문헌 지식 부재로 단정하지 않는다.

기존50개는 이미 개발·회귀에 사용된 자료다. 독립 최종 평가셋이 아니다. 사용자 승인 표현은 허용 가능한 참조이며 유일한 정답이 아니다. 사람 자연스러움 점수나 개선율을 새로 만들지 않았다.

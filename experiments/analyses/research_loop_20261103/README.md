종료: 실행 원본·단계별 원인·비교표·지원 누락 목록을 보존하고, 각 단계의 완료/실패를 구분한다. 한 번의 동결 실험 후 같은 코드를 계속 고치며 수치를 올리지 않는다. 재실행은 원인이 확인된 수정에 한한다.

# ⑤ 미지원 범위: 확대된 것과 남은 것

이번에는 과거 긍정/부정 계사 한 묶음을 r10 후보로 정제하고 실제 조회·전달·생성까지 검사했다. 전면 확장은 끝나지 않았다. 기존50에서 전달되지 않은39목표를 private/unsupported39.json에 모두 기록했다. 이는39종 문법이라는 뜻이 아니다.

|다음 묶음|필요한 일|완료 기준|
|---|---|---|
|반말 평서 다/ㄴ다|D02 PDF107–115의 실현 사실과 입력 해체→해라체 선택을 분리. 형용사 현재/동사 현재/과거 조건별 연결|새 어휘의 조건·반례 검사, 자연스러운 선택 범위 확인. 모든 어/아를 다로 강제하지 않음|
|질문 나요/을까요/죠|정보질문·제안·확인의 기능 차이를 분석 질문과 KG 조건에 연결|같은 형태의 다른 기능에서 잘못 적용하지 않는지 확인|
|명령·부탁·약속|해주세요/마세요/을게요 등의 기능과 높임 보존, 자료별 실현 선택|용법군별 근거·충돌·새 단문 검증|
|의존명사·보조용언·복문|거예요/계세요/인용·절 연결의 분석과 실현을 분리|형태 분석 오류와 KG 누락을 구분하고 실제 trace가 끝까지 이어짐|

지금 모든 묶음을 한꺼번에 활성화하면 지식·분석·전달·생성 변수를 다시 섞게 된다. 새 규칙에서도 생성 오류가 남아 있으므로, 이번에는 확장 후보의 전체 위치와 근거 작업을 넘기고 같은 조건의 비교 파일럿을 우선한다. 반말 다가 문헌에 없어서 못 하는 것이 아니다. '문헌에 존재'와 '이 입력에서 적절한 선택'을 분리한 변환 규칙의 검증이 남았다.

다음 연구의 확장 순서는 반말 평서 → 공손 질문/확인 → 부탁·명령·약속 → 보조용언·절 연결이다. 단, 독립 평가셋은 지원 범위를 고정한 뒤 새로 수집한다.

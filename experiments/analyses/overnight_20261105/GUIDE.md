## 코드·검증

`explain_research.py`는 저장된 run과 KG 사본을 읽어 `private/guide.html`, `guide_cases.json`, `guide_manifest.json`을 만든다. `guide.css`와 `guide.js`는 비공개 출력 폴더에도 복사된다. manifest에는 읽은205개 데이터 파일의 해시가 있다. 원문과 참조가 다른 입력 버전이면 생성을 중단한다. 구조 통계는 실제 그래프에서 계산한다.

보고서는 50건의 모든 출력이 잘못됐는지 새로 판정한 문서가 아니다. 상세 진단은 요청한5사례이며, 나머지는 단계별 실제 기록과 사람 검토 필요 상태를 제공한다. 영어 코드값은 세부 근거에만 원래 식별자로 남긴다.

기존 보고서·야간 실험 결과를 덮어쓰지 않았다. 변경 전 복구점은 `ed3b9ef23e7d4517ef331573b3bcf74b32616dc3`이다. 변경 후 체크포인트는 `local/version_history/latest.json`에 기록한다. GitHub push는 이번 작업 범위에 포함하지 않는다.

# 두 검토자 결과 반영

## 실제 활용
기존 Orca의 Codex/Claude 두 검토자가 계획·후보·개발 결과·파일럿 전달 코드·실제 결과를 독립 검토했다. 상대 원문을 읽지 않도록 지시했고 원본 KG/코드 수정 권한은 주지 않았다. 문제 위치→실제 근거→수정안으로 기록. 전송 문구와 수신 확인은 private/reviewers에 보존했다. 모델 합의는 언어 사실이나 사람 평가의 대체가 아니다.

## 반영한 것
- 조건의 문헌 사실/구현 범위 구분, 부정계사 nominal_kind 제거.
- 기대 완성형이 요청에 없는지 전체 전달 검사.
- 과거 경쟁형/다른 술어의 과거 근거는 직접 인증과 구분된 문맥 관계.
- 텍스트 이중 인코딩 제거. 실제 송신 메시지에서 정보 동일성 검사.
- N에도 공통 분석을 주되 KG 선택 여부는 누설하지 않음.
- 입력별1목표 사전 확인, 단회·순환 순서·최대120호출·단계별 실패 카운터.
- 30전체 전송·2,434artifact·109코드 스냅샷·234생성 원시 출력 대조. 불일치0.
- 형식 차이7개를 지원3/미지원4로 분리. 형식별 반복 변동 미측정 명시.
- 입력+출력 토큰으로 비용 열 이름 정정.
- 어 탈락/과거 소실/사건·높임 변화 의심/분석기 경고/미검사를 구분.
- 최종 보고서·실행 원본까지 포함하는 로컬 비공개 복구 묶음 준비.

## 채택하지 않거나 한정한 의견
- 새8개 단문 성공만으로 r10 운영 채택: 보류. 회귀·다른 단문 실패 확인.
- 전역 unknown 차단 해제: 영향 범위 입증 부족으로 미채택. 실제 차단1/62를 전체 원인으로 설명하지 않음.
- Claude의 상대높임 하강19/25는 검토자 판독이다. 코드의 자연스러움/보존 정확도로 승격하지 않고 검토 원문에 남김.
- 정규화가 출력 오류를 ‘만들었다’는 인과 단정은 채택하지 않음. 전달에 충돌 정보가 있고 관련 오류가 관찰됐다는 것까지 확인. 별도 원인 통제 필요.
- ‘생성 실패가 세 실험 모두 재현’이라는 검토 문구는 채택하지 않음. 새 개발8개에서는 계약 실패0이며 회귀·쉬운 파일럿에서 실패했다.
- 목표 지역을 새로 경북/부산 중 하나로 강제 선택: 사용자가 이미 경상도 범위로 승인했으므로 필수 선행 결정으로 추가하지 않음. 본 평가에서는 평가자 지역·연령과 허용 표현 차이를 기록.
- 쉬운30을 독립 평가로 사용: 불가. 사용자/다른 작성자의 독립 자료와 어휘·템플릿 분리 필요.

## 현재 판단
실행·집계 무효화 오류는 검토에서 발견되지 않았다. 이 말은 품질 인증이 아니다. 같은 지시 탐색은 종료하고 원본을 백업한 뒤 미팅으로 넘긴다. 최종 운영 채택과 논문 평가 범위·평가자 결정이 남는다. r7유지는 기준선 보존이며 r7품질 인증이 아니다.

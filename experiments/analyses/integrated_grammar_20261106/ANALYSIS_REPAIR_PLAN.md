# 분석 정의 보완: 한 번만 재확인

2026-11-06 개발30의 두 독립 검토에서 문장 기능과 관계 방향을 잘못 선택한 사례가 확인됐다. 같은 지식을 전달받은 뒤 과거를 지운 사례와는 다른 문제다.

## 비교 설계

- 기준: `20261106T051728566435Z_integrated_grammar_development`의 같은18입력.
- 바꾸는 것: 분석 시스템 지시에 기능·높임·관계 방향의 정의를 추가한다.
- 고정: 입력, Kiwi 관찰·결속 코드, 분석 스키마, KG r2, 기존 참고 선별, 생성 지시, 모델·temperature·seed·출력 한도. 수정된 참고 필터는 이 실행에 넣지 않는다.
- 예상: 금지/청유를 요청으로 합치는 분석, 관계의 출발·끝점 혼동이 줄면 관련 조건 조회가 달라질 수 있다. 과거 보존 오류나 자연스러움까지 해결된다고 예상하지 않는다.
- 종료: 고정18입력에 분석1+생성1, 최대36호출 한 번. 같은 지시 수정 반복·성공할 때까지 재시도·입력 교체 없음. 전체 프로그램200호출 상한과 연속3기술실패 중단을 유지한다.
- 해석: 노출된 개발자료의 전후 관찰이다. 독립 정확도나 개별 지시 문구의 인과효과가 아니다. 거부 관계가 줄어도 관계 자체를 덜 제안한 결과일 수 있으므로 유효·거부·누락을 함께 집계한다.

## 참고 전달 보완은 별도 검사

기존30과 종료 후50의 저장 분석으로 모델 호출 없이 재생한다. 전체 검색 결과는 유지하면서 명확한 단위·방향·어간 조건 불일치만 전달에서 제외하고, 관계 해시·반복 관리 필드를 덜어낸다. 누락·실패로 재생 불가능한 입력도 분모에 기록한다. 이 대안 패킷은 이번18의 실제 모델 요청과 다르다. 분량 감소를 번역 품질 개선으로 보고하지 않는다.

## 채택하지 않은 검토 제안

- 같은 절의 모든 단위에 시제·화행을 같은 값으로 강제: 내부·외부 절과 용언 역할이 다를 수 있어 미채택.
- `계세요`처럼 보이는 형태를 일괄 차단: 정상 계사 구성까지 막을 위험이 있어 미채택. 관찰 오류는 별도 문제로 남김.
- 축약된 조사 위치의 변환을 일괄 차단: 명사와 조사를 함께 바꾸는 정상 용법도 있어 이번에는 적용하지 않음. 변환 여부 자기보고를 실제 변화로 세지 않는다.
- 모델이 과거를 지울 때 코드로 과거형 복원: 최종 생성 주체가 바뀌므로 미채택.

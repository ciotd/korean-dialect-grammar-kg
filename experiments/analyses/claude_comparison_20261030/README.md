# Claude 50문장 비교 · 2026-10-30

기존 Claude Reviewer가 확정 입력 50개를 번역했다. 이번 요청에는 최신 Qwen 출력과 KG 카드를 보내지 않았으나, 기존 세션이므로 이전 연구 노출이 있다. 맹검·정답 데이터로 간주하지 않는다.

## 확인한 것

- 50개 번역, Single/Multi 기존 출력 100개, 핵심 문법 후보의 실제 조회·전달·선택 기록을 대조했다.
- `-네예`, `-라예`: 문헌·카드·조회에는 있으나 해당 문장의 최종 48개 전달에서 제외됐다.
- `-ㄹ게 → -께`: D04 PDF 28쪽에 대응과 용례가 있으나 카드 문자 검색에서는 직접 대응을 찾지 못했다. `-께예` 목록 카드와 완성된 약속 변환 규칙은 구분한다.
- 원인 연결 카드는 전달·선택되었지만 `생각아가`, `재밌아가`가 생성되었다. 카드 공급만으로 설명되지 않는 조합·검사 문제가 있다.

## 범위와 한계

7종 원본 PDF 해시가 기존 추출본과 일치함을 확인하고 474쪽 추출 텍스트를 검색했다. 핵심 표 3쪽은 렌더링하여 확인했다. 이번에 474쪽 전체를 다시 정독한 것은 아니다.
각 문장의 핵심 문법 후보를 연결했으며 모든 어휘 변화·지역 자연스러움·의미 등가를 검증한 것은 아니다. 관련 카드의 존재나 조회 누락 자체를 적합성 또는 실패 원인의 인과 증명으로 해석하지 않는다. 자연스러움 점수는 계산하지 않았다.

## 재현과 실행 범위

`compare.py`는 저장된 번역·실험 로그·추출본을 읽어 비교 파일을 만든다. 네트워크 모델 호출이나 KG 수정은 하지 않는다. 로컬 경로와 당시 동결된 입력·로그가 필요하다.

Qwen 기준 실행: `20261030T020345468863Z_cards_single_regression`, `20261030T020345468863Z_cards_multi_regression`.
Claude 모델 식별자는 실제 세션 기록의 `claude-fable-5`이다.

보고서 경로만 기존 대시보드에 연결했다. 관리 서버 테스트 34개 통과, 실제 HTTP 보고서/스타일 일치 및 원시 JSON 비공개 확인. KG와 생성 파이프라인은 변경하지 않았으며 새 Qwen 호출은 0회다.

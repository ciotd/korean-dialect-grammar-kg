# 조건별 검사와 전달 보완 — 2026-11-10

## 이번 질문
56개 규칙의 57개 조건 갈림길이 입력의 특징에 따라 허용·거절·판단보류를 제대로 구별하는가? 조회된 지식에서 생성에 필요한 제한사항이 전달 중 사라지는가?

## 범위와 종료
1. 직전 구조 검사와 KG를 보존한다. 전달 필드의 누락과 실제 경로 기록을 수정한다. 문법 조건은 임의로 넓히지 않는다.
2. 기존 990개 논리 사례를 재사용하여 모든 57분기의 허용·거절·미확정 및 관계 부족을 확인한다. 이는 KG 내용의 언어학적 정답 검사가 아니다.
3. 기존 57개 자연어 예문을 재사용하되 Claude가 문장과 조건을 대조하고 적용/비적용/미확정 예문을 검토한다. 실제 모델 분석 실험과 사람이 지정한 분석값 검사를 구별한다.
4. Codex는 수정 코드, 누락 없는 검사 범위, 기대값의 순환 논증을 확인한다. Claude는 조건·설명·예문의 충돌과 옛 메모 제거 가능 범위를 검토한다. 두 검토자는 운영 코드/KG를 직접 수정하지 않는다.
5. 이번 종료는 구조/전달 검사 결과 및 자연어 검사 준비도를 항목별로 확인하는 시점이다. 해석이 불확실한 규칙은 보류 목록으로 남긴다. 자연어 적합성이 확인되지 않은 문장을 모델에 넣고 성공률로 집계하지 않는다.

## 다음과 대안
검토된 예문에서 분석→조회→전달→생성을 연결한다. 지식이 도착했으나 생성만 실패한 경우 같은 지식 고정 생성 비교로 넘긴다. 문헌 충돌은 사용자 판단을 요청하고, 자동 조건 완화/정답 암기로 우회하지 않는다.

논문에서 이번 결과는 구현의 조건 판정·정보 전달 검증이다. 자연스러움, 독립 정확도, KG 우월성의 증거가 아니다. 기존 50건은 노출된 회귀셋으로 유지한다.

# 실제 문장 분석에서 필요한 문법 지식에 도달하는가

2026-11-07. 사용자 요청: 새 KG의 내용·조건 점검, 실제 입력 분석을 통한 지식 도달 확인, 문제 원인·수정안 보고, Neo4j 시각화와 규칙/분기 설명.

## 질문과 범위

기존 저장 형식의 전후 동등성이 아니라 **문장에 필요한 지식이 선택되는지**를 확인한다. 새 저장 KG의 규칙56/분기57 전체 목록을 검사하며, 기존50문장 전부에 필요한 지식과 미지원 사항을 연결한다. 기존 개발·회귀·재시험의 실제 분석99건도 재사용하여 도달 범위를 집계한다.

1. 현재 Neo4j의 원본을 논리 백업하고 새 버전을 다른 dataset_id로 적재. 기존 버전 전체 속성 보존 및 새 파일과 DB 일치 검사.
2. 56규칙 전체에 자연어 점검 예문을 작성. Kiwi가 필요한 대상·형태를 실제로 제공할 수 있는지 검사. 예문은 개발/진단용이고 독립 평가 자료나 방언 정답이 아님.
3. 기존50문장의 실제 Qwen 분석과 필요한 규칙을 대조. 담당 위치·뜻·조건·관계·선택 여부·전달 여부를 연결. 분석 파일 없는 입력은 실패로 남김.
4. 필요한 값이 없거나 틀린 경우 위치 관찰/모델 의미 판단/관계 연결/지식 조건/미지원으로 나누어 수정 제안. 수동으로 의미값이나 관계를 보충하는 진단은 실제 모델 결과와 분리하고 시스템에 채택하지 않음.
5. 읽기 쉬운 보고서, 50문장 상세, 56규칙 점검표, Neo4j 탐색 질의와 개념 설명 제공.

## 고정·중단·한계

- KG·기존 분석·과거 출력은 수정하지 않는다. 기대 규칙은 입력 문장의 기능에 대한 리드의 점검 의견이며 독립 정답 라벨로 주장하지 않는다. 틀릴 수 있는 판단/문맥 모호함은 표시한다.
- Qwen 서버 연결을 시도했으나 URLError. 새 모델 호출은 수행하지 않고 저장된 실제 분석을 사용한다. 새 예문은 현재 Kiwi/질문 스키마까지 확인하며 Qwen 의미 판단 이후의 도달로 세지 않는다. 서버를 원인으로 단정하지 않는다.
- 조건 분기 구조 검사로 문법 내용의 타당성을 대신하지 않는다. 원문 출처는 별도 기록에서 확인한다. 이번에 원문7종 전체를 다시 정독했다고 주장하지 않는다.
- 종료: 전체50문장에 도달/실패/미지원/분석미확보 상태가 있고, 전체56규칙에 저장 분석에서의 도달 현황 및 새 예문의 형태 분석 점검이 있으며, 발견 문제에 실제 값과 수정 권고가 연결됨. 전체 KG의 의미 검증 완료는 아님.
- 사용자 승인 없이 말높임·시제·의미의 조건을 느슨하게 만들지 않는다. 큰 언어 해석 충돌은 사용자 검토로 남긴다. 일반 코드 수정이 필요하면 별도 작은 변경과 회귀 검사로 다루며 원인 근거 없이 수정 범위를 넓히지 않는다.
- Neo4j는 새 KG를 탐색할 수 있는 동일 버전 사본이다. 실제 Qwen 파이프라인의 조회 엔진을 파일에서 DB로 바꾼 것은 아니다.

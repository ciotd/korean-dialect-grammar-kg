문장 읽기 → 문법 설명 찾기 → 어디를 어떻게 바꿀지 확인 → 글자 조합·원문 보존 확인 → 반영 또는 보류

실제로 바뀐 것

기존 문제이번 수정
찾은 설명과 다르게 바꿈카드·목표 형태·원문의 어느 형태소를 바꾸는지 연결하고 대조한다.
글자를 잘못 붙임선택한 받침을 합치고, 일부 잘못된 활용은 원래 형태소와 Kiwi로 다시 조합한다. 바꾼 내역을 남긴다.
띄어쓰기가 있으면 실패한 단어가 여러 단어로 바뀌는 표현을 허용한다. 선택한 문법 설명에 맞는지도 확인한다.
동사·과거 표시가 달라짐원래 형태소를 남긴 조합과 비교하고, 다르면 재분석한다. 의심되는 수정은 보류한다.
참고 설명을 수정 명령으로 사용관찰·분류·금지 정보를 구분한다. 해결되지 않은 중요한 조건도 표시한다.
여러 단어를 묶다가 뜻을 잃음각 수정이 가리키는 원문 위치를 지정한다. 기존 단어를 보존하는 조합을 확인할 수 없으면 그 묶음을 보류한다.
샀어를 무조건 샀지로 바꿈DEV002 제한을 지킨다. 다른 문장의 -지/-제는 응답·확인 등 별도 근거를 요구한다.
한 수정 때문에 전체가 실패문제가 있는 수정과 독립된 수정을 구분한다. 함께 처리해야 하는 묶음도 기록한다.
옛 요청이나 다른 결과를 잘못 연결원문·분석·카드·계획의 버전을 대조한다. 서로 다르면 적용하지 않는다.
유지·실패·보류를 혼동출력 없음, 원문 유지, 일부 반영, 수정 보류를 나눠 기록한다. 불필요한 생성 호출도 생략한다.

확인한 결과

  • 프로그램 검사 181개 통과. 방언 정답률을 뜻하지 않습니다.
  • 기존 50문장·100개 결과를 다시 확인했습니다. Qwen을 새로 호출하지 않았습니다.
  • 과거 실패 21개는 실패 기록으로 보존했습니다. 그중 15개는 수정 계획이 없어 새 검사도 할 수 없었습니다.
  • 원본 근거 파일 446개는 그대로입니다.
  • Codex 8개·Claude 8개 지적을 검토해 반영했습니다. 두 검토자는 수정 중간 코드를 보았으며, 최종 수정본은 로컬 검사로 확인했습니다.

아직 해결됐다고 말할 수 없는 것

  • Qwen이 문장의 뜻과 문법을 처음부터 제대로 읽는지.
  • 어떤 어미가 그 상황에서 자연스러운지, 높임과 의향이 완전히 유지되는지.
  • 문법 설명에 없는 조건과 모든 예외. 모든 KG 지식이 실행 가능한 규칙이 된 것은 아닙니다.
  • 새 검사가 정상 표현까지 너무 많이 보류하는지. 실제 재실험으로 확인해야 합니다.

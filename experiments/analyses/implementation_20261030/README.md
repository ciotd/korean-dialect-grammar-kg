프로그램의 잘못된 수정 처리와 기록 방식을 고쳤다. 새 Qwen 번역 실험은 실행하지 않았다.

- 기존 50개 입력·100개 결과를 새 검사로 확인했다. 과거 실패 21건을 성공으로 바꾸어 세지 않는다.
- Codex·Claude가 중간 구현에서 각각 8개 문제를 지적했다. 수정 후 로컬 테스트를 수행했다. 검토자가 최종본을 재승인한 것은 아니다.

## 코드가 하는 일

1. 분석과 카드, 원문 위치를 묶는다. 카드마다 실제 바꿀 형태소를 지정한다.
2. Qwen이 고른 형태와 출력이 맞는지 확인한다. 단순 문자 일치와 문법적 옳고 그름은 다르다.
3. 원래 형태소에 새 어미를 붙이는 공통 처리를 Kiwi로 수행한다. 일부 글자 조합 오류만 보정하고 보정 전후를 남긴다.
4. 원문 유지, 보류, 일부 반영, 호출 실패를 나눠 기록한다.

`src/kg_runtime/edit_contract.py`는 편집 검사, `suffix_composition.py`는 공통 활용 조합, `card_interpretation.json`은 자료 역할·일부 조건의 해석이다. `card_pipeline.py`와 `card_experiment.py`에서 두 모델 구조에 연결한다. 문법 규칙마다 Python 함수를 추가하는 구조가 아니다.

## 다시 확인하기

프로젝트 루트에서 실행한다. 아래 명령은 Qwen을 호출하지 않는다.

```powershell
python -m unittest discover -s tests -v
python experiments/analyses/implementation_20261030/replay_records.py
```

`private/replays`는 재검사별 원본, `private/replay.json`은 최신 조회본이다. 옛 기록에 없는 목표형과 수정 의존성은 일부 추정하거나 미확보 상태로 남는다. 재조립된 문장은 새 Qwen 출력이나 성능 측정값이 아니다. 실패 원본 상태와 감사 상태를 따로 보존한다.

`private/reviews`와 `reviewer_dispositions.json`에 검토자 원문과 총괄 판단, `private/code_hashes.json`과 `final_code`에 최종 코드 사본·해시가 있다. private 자료는 Git clone만으로 복원되지 않는다.

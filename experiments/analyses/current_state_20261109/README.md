- [재집계](overview.json): 현재 그래프·직접 모듈 연결·작업대장·최근 실행 고유 규칙 수.
- [재집계 코드](collect_snapshot.py), [보고서 생성](build_report.py), [브라우저 검사](browser_qa.mjs).

핵심: 1,491노드/5,037관계, 56규칙/57분기, 26작업묶음 부분 진행. 최근50에서 고유26규칙 조건 통과·전달,22규칙 사용 신고. 사용 신고는 올바른 실현이 아니다. 출처 전용 자료는 분리됐으나 설명문 속 쪽수·검토 메모는 일부 남았다. 미정제721항목은 검색/기록되지만 최근 작성 요청의 지식에는 포함되지 않았다.

현재 기본은 Kiwi+첫 연결 보완, 최근50은 후속 질문 보완 후보. 실제 모델4역할이며 의미·관계 내부 분업과 Kiwi 경로의 별도 계획 담당은 미구현이다. Neo4j는 저장된 시각화 사본이며 현재 실행 조회는 파일 기반이다.

검증: 현재 KG 해시와 최근 실행 일치, 실행 코드12파일 해시 변경 없음, 작성49요청의 knowledge=selected 일치. 브라우저에서26묶음 검색·펼침, 데스크톱/모바일 가로 넘침, 스크립트 오류를 검사한다. 이것은 문법의 정확성 검사나 새 실험이 아니다.

다음은 전체 항목 역할·연결·규칙 대응·혼합 메모·조건 통과 미관찰 이유의 목록 검사. 자료가 부족하면 미확인으로 남기고 근거와 다음 조치를 붙인다. 사용자에게 새 문법 판단을 요청할 항목은 이번 범위에 없다.

# 어미 교체 범위 수정과 50문장 재실험

[결과 화면](http://127.0.0.1:8767/reports/scoped-repair-20261030/report.html) · [실시간 진행](http://127.0.0.1:8767/work)

## 무엇을 고쳤나

카드는 ‘요만 예로 바꾸기’를 안내했지만 기존 실행 코드는 더 큰 어미 전체를 교체하는 경우가 있었다. 예를 들어 `나왔어요 → 나왔예`처럼 앞부분이 사라질 수 있었다. 이번에는 해당 지시가 있는 카드 두 장을 공통 부분 교체 동작에 연결했다. `나왔어`를 보존하고 마지막 `요`만 `예`로 바꾼다.

이는 Qwen이 더 잘 학습한 결과가 아니라 **프로그램의 조합 처리 수정**이다. Qwen의 원래 제안, 보정 이유, 실제 반영 결과를 모두 따로 저장한다. 카드 두 장의 내용과 원본 KG는 바꾸지 않았다. 문장마다 별도 함수를 작성하지 않았으며, 공통 동작 하나에 카드별 데이터 설정을 연결했다.

## 무엇을 비교하나

1. **저장된 응답 재생**: 직전 v3 Single/Multi 응답 100개를 다시 읽어 코드만 달리 적용한다. 새 모델 호출은 없다. 20개 출력이 바뀌고 기존 실패 5개는 남았다.
2. **새 Qwen 실행**: 같은 50개 입력·저장된 분석·카드 목록·프롬프트·모델 설정으로 Single/Multi를 실행한다. 100개 결과 기록을 만든다. 입력 데이터가 100문장으로 늘어난 것이 아니다.

새 실행과 직전 결과의 비교는 **서로 다른 시점의 비교**다. 이전 코드로 같은 시점에 다시 실행한 대조군은 없다. 코드 자체의 효과는 1번 재생 결과로 따로 확인한다. 계약 식별값과 그에 따른 모델 응답/후속 작업 지시는 달라질 수 있다. 반복은 조건당 1회이며, 변화 수는 정확도나 자연스러움 점수가 아니다.

## 변경 파일과 기록

- `src/kg_runtime/card_operations.json`: 기존 카드 두 장과 부분 교체 동작을 연결하는 데이터. 정확한 카드 내용 해시도 확인한다.
- `src/kg_runtime/scoped_operations.py`: 공통 조합·보존 검사. 따옴표 내부, 표면에 요가 없는 축약형, 지원하지 않는 혼합 편집은 적용하지 않는다.
- `src/kg_runtime/edit_contract.py`: 계획 검증·조합 단계에 연결. 모델의 유지/보류 판단은 강제 적용으로 바꾸지 않는다.
- `tests/test_scoped_operations.py`: 과거·높임·부정·파생 서술어 보존, 잘못된 카드/위치/범위, 유지/보류 및 워커 검증.
- `replay.py`: 이전 응답 재생. `run.py`: 승인된 새 모델 실험. `evaluate.py`: 기록에서 통계·HTML만 재생성.
- `private/active_run.json`: 현재 Batch/Run과 직전 비교 대상.
- `private/replay_summary.json`, `private/summary.json`, `private/cases.json`: 재생·실제 실험을 구별한 집계와 입력별 결과.
- `private/reviewer.json`: 독립 구현 검토. 실제 실험 결과 검토는 별도 기록한다.

원본 요청·응답·분석·카드·계획·코드/KG 해시는 각 Run에 남긴다. 이전 분석 시간·호출은 이번 실험 비용에 더하지 않는다. QUAL002의 기존 분석 실패는 재분석하지 않고 유지한다. 사용자 승인 기준 표현은 생성 요청에 추가하지 않았다.

## 검증과 남은 범위

관련 자동 검사 **93개 통과**, 독립 검토에서 발견한 결과 필드 접근 오류와 따옴표 내부 적용 문제를 수정했다. 이 검사는 전체 방언 자연스러움 평가가 아니다. 다른 어미의 활용, 카드 선택 자체, 조사 선택, 분석 오류, 문맥에 맞는 자연스러운 문장 구성은 별도로 남는다. 이번 실행 도중 결과를 보고 코드를 다시 바꾸지 않는다.

이 실험의 근거는 사용자 ‘진행’ 승인과 대시보드 `scoped-repair-experiment-20261030` 결정 기록이다. 최종 통계는 실행 완료 후 아래에 추가한다.

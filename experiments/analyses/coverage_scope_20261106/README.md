## 4. 왜 전체 KG가 있는데도 일부만 사용했나

현재 실행기는 선택된 작은 그래프의 구성들을 확인한다. 맞는 규칙이 있으면 형태·조건·보존 정보를 전달하고, 없으면 미지원으로 기록한다. 큰 기존 KG를 다시 검색하는 경로는 연결하지 않았다. 따라서 기존 원문/설계 항목을 보유했다는 사실과 실제 생성에 활용했다는 사실 사이에 공백이 있다.

이 공백은 단순 active 스위치를 켜서 해결되지 않는다. 그렇다고 문헌 정보가 모두 정제될 때까지 조회에서 숨겨야 하는 것도 아니다. 확장에서는 **정제해 적용 조건을 확인한 지식**과 **관련은 있으나 적용 여부가 미확정인 자료**를 구분해 반환할 수 있어야 한다. 후자를 확정 수정 명령으로 전달하지 않으며, 어떤 정보가 실제 문장 변경의 근거가 됐는지 기록한다. 미지원 탐색과 생성 활용 정책은 각각 검사한다.

## 5. 사용자 위임에 따른 작업 범위

동사, 형용사/계사, 명사류, 조사, 어미/종결, 높임, 절 연결, 시제/상/양태/부정, 사동/피동/보조용언을 **한 통합 확장 작업의 대상**으로 한다. 기존 ‘요청 하나만 다음에 추가’하는 계획보다 범위가 넓어졌다. 어휘·표기·출처 관리도 이 9분야에 필요한 만큼 공통 지원으로 포함한다. 모든 분야에 억지로 방언 치환을 하나씩 만드는 방식은 쓰지 않는다. 표준어와 공유하는 문법은 보존 지식으로 기록할 수 있다.

리드와 기존 Orca 두 검토자에게 일반적인 설계·구현·검사·보완 결정을 위임한 것으로 기록한다. 단계마다 형식적 재승인을 요청하지 않는다. 모델 합의를 문헌 증거로 대신하지 않는다. 연구 목표를 바꾸거나 외부 공개·새 비용/서비스 계약·사용자 말투 선호의 실질적 충돌처럼 위임 범위를 벗어나는 결정만 요청한다.

## 7. 두 검토자 검토를 반영한 핵심 결정

두 검토자는 이번에 각각 저장 그래프와 관련 코드를 읽고 독립 의견을 제출했다. Claude는 문법 지식·자료의 성격과 분석 누락을, Codex는 실제 조회/전달 경로와 통합 확장 구조를 확인했다. 코드 변경이나 새 모델 실험은 하지 않았다. 검토 원문과 리드의 대조는 private/에 보관한다.

**합의할 수 있는 구조 문제:** 현재 처리 대상은 종결어미가 있는 어절 중심이다. 조사·명사구·두 절 사이의 연결·사동/피동 참여자를 표현하려면 대상 추출과 정보 전달 구조도 함께 넓혀야 한다. KG에 규칙 수만 더해 넣어서는 9분야가 작동하지 않는다. 또한 두 규칙을 동시에 써도 되는 경우와 실제 충돌을 구분해야 하며, 여러 후보가 있다는 이유만으로 전부 보류하는 방식도 고쳐야 한다.

**구현 방향:** 기존 조건 조회기를 재사용하되, 문장–절–서술어–명사구–조사 구간–보조용언의 연결을 공통 표현으로 만든다. 새 용법마다 별도 Python 판단 함수를 만드는 방식보다, KG에 조건·관계·실현·근거 역할을 선언하고 공통 조회/전달 코드가 읽는 방식으로 확장한다. 기존 큰 KG의 자료도 접근 가능하게 연결하되 미정제 자료를 곧바로 확정 변환 명령으로 사용하지 않는다.

**리드가 보완한 검토 의견:** SourceAtom에 저장된 비활성 상태는 옛 설계 명세이며 최근 실험의 실제 차단 코드와 동일하지 않다. 옛 KG에 새 SemanticRule 유형이 없다고 문법 지식이 전혀 없다고 말하지 않는다. Construction54·AnalysisConcept48 등은 공통136개에 포함되므로 중복 합산하지 않는다. 독립 블라인드 평가 미완료와 기존 사용자 표현 피드백 부재는 다른 말이다.

**진척 표의 한계:** coverage.json은 저장 그래프·최근 코드·실험 기록을 대조한 리드의 현재 평가다. 26묶음 전체 원문을 이번에 새로 정독한 결과는 아니다. 다음 판본에는 각 세부 용법별로 원문 근거, 정제 결과, 실제 조회 검사, 생성 Run ID, 사람 평가 여부를 연결한다. 이를 갖추기 전에는 묶음별 완료율을 임의 계산하지 않는다.

이번 완료 범위는 전체 규모 재집계, 12모듈·26묶음 현황표, 독립 검토, 통합 확장 범위·권한·종료 기준 기록이다. 전체 KG 정제·9분야 구현·Qwen 재실험을 완료한 것이 아니다.

# 설계·구현 검토에서 내린 결정

## 이번 실험에서 고정한 것

기존 Qwen 분업의 형태/절 분석 전체와 기존 Kiwi 파이프라인 전체를 비교하지 않는다. 원문 위치와 이전 최초 Qwen 절 구획을 공통으로 고정하고, 어절별 형태소 기본형/품사 공급자만 바꾼다. 공통 observe_units로 단위를 만들고 기존 meaning/writer/reviewer를 재사용한다. 자동 재분석·재작성은 두 경로 모두 끈다. 기존 운영 기본값은 바꾸지 않았다.

## 남긴 해석 한계

고정 절 구획은 Qwen의 기존 추정이며 정답이 아니다. 현재 KG와 공통 연결은 Kiwi 계열 표기와 맞물리므로 일반 형태소 분석 정확도 비교가 아니다. 같은 seed도 서버의 동일 응답을 보장하지 않는다. 6쌍 한 번의 개발 진단이며 사람의 독립 자연스러움 평가가 없다. 이전 분업 대비 개선 전체를 분석기 하나의 효과로 주장하지 않는다.

## 결과 검토와 실제 결정

6쌍/12경로 모두 완료,42호출,95,003토큰. 같은 후속 지시·모델·설정·코드에서 형태 공급자만 교체한 통제를 두 검토자가 확인했다. 원문별 실제 데이터·스키마는 분석 차이에 따라 달라지므로 같은 분석값을 받은 생성 비교는 아니다. 4문장 출력 동일은 품질 정확도가 아니다. Kiwi를 다음 개발 기준 후보로 권고하되 기본 경로 전환·자동 재작성 채택·50건 확대는 하지 않았다.

Claude가 처음에는 Kiwi05의 제→내를 KG 문제로만 분류했으나, 리드가 실제 instruction에 저의→내가 없음을 제시해 재검토를 요청했다. Claude는 ‘생성 실패가 아니다’를 철회하고 적용 범위와 생성 일반화의 복합 문제로 정정했다. 복원형 전체 차단 제안도 특정 규칙의 범위·겸양 보존 검토로 좁혔다. 원문 의견과 추가 정정은 모두 보존한다. Codex도 동일 사례를 지식 전송 누락만으로 설명할 수 없다고 지적했다.

다음은 공통 연결의 누락/미해석 선어말 표시, 의미 분석의 금지·보조 관계, 복원 조사 규칙과 겸양 보존 점검이다. 참조 완성형을 넣거나 이번 문장을 외우는 방식은 사용하지 않는다. 후속 보완은 아직 실행하지 않았다.

## 실험 후 기록 관리 수정 — 모델 재호출 없음

기존 등록기는 문장 ID가 한 실행 안에서 하나씩만 나온다고 가정했다. 이번은 ID마다 qwen/kiwi 두 행이므로 최종 등록이 실패했다. 원본 결과는 그대로 두고 색인에서 source_input_id와 복합 표시 ID를 구별하고 paired_morphology_v1 집계 검사를 적용했다.12행 등록과 가벼운 무결성 검사가 통과했다.

전체 해시 검사는484개 중 progress.json 하나가 다르다고 보고했다. 마지막 진행률 저장이 목록 생성 뒤에 있었기 때문이다. 나머지483파일은 일치한다. 원본 해시 목록은 덮어쓰지 않고 management_recovery.json에 해당 실패를 보존했다. 다음 실행기의 저장 순서를 고치고 모의 중단 실행에서도 모든 기록 해시가 일치하는 검사를 추가했다. 실제 비교를 다시 실행하거나 결과를 정정하지 않았다. 실행 중 코드 고정 성공과 실행 후 관리 코드 수정은 다른 시점이다.

# 공통 문법 136개 기준 자료 대조 — 수정 전 진단

사용자 요청에 따라 공통 설계 자체의 충분성, 분할, 출처를 검토했다. 연구 질문은 ‘현재 136개가 범용 공통 문법 틀이라는 원래 목표를 뒷받침하는가’이며, 다음 KG 보완 범위를 결정하기 위한 진단이다. 기존 KG·실행 코드는 변경하지 않았다. 새 모델 호출은 없다.

최종 설명은 `private/20261107T050652077810Z/report.html`, Archify 전체 그림은 같은 폴더의 `overview.html`이다. 초기 초안과 실패는 지우지 않고 `superseded.json`으로 정정 사유를 남겼다. 이전 연결 감사와 달리 이번에는 언어 범위와 근거를 조사했다. 공통 항목이 있는지, 실제 구현됐는지, 언어적으로 타당한지는 다른 질문이다.

## 초기 목차 차용 사실의 복원

초기 KG v3 사용자 대화에서 다음 사실을 확인했다. 시간은 KST이다.

- 2026-10-13 21:10: 『한국어 문법 총론』의 목차를 공통 체계 설계의 참고로 삼자는 제안.
- 같은 날 22:30: 사용자는 전체 목차를 검토 대장으로 옮기라는 뜻이 아니라, 하위 요소·관계·중점을 논의하는 데 참고하자는 뜻이라고 명확히 설명했다.
- 같은 날 22:39: 『한국어 문법 총론 1권』 전체 목차를 직접 제공했다. 번호 항목 224개, 최하위 171개이며 장 제목 4개는 이 수에서 제외했다. 붙어 있던 4.5.4/4.5.5 번호만 분리해 계산했다.
- 같은 날 22:39·22:47: 1장 일반론을 제외하고, 2장 상세 논의를 미루고, 3장부터 개념 설명을 진행하기로 했다.

당시 응답은 2025-08-30 개정판을 안내했다. 해당 서지 페이지에서 저자·판본·발행일을 재확인했다. 서점 정보는 서지 확인에만 사용하고, 문법 내용 판단은 사용자 제공 목차·공식 보고서 본문·기존 설계를 대조했다.

따라서 ‘책 전체 본문 미제공’이라는 설계 문구만으로 목차 차용 여부나 의도적인 배제 이유를 추론할 수 없다. 이번 초기 대화 확인으로 앞선 설명을 정정했다. 책의 목차는 출발점이지만 136개가 원목차의 전사본은 아니다. 원목차 4장 → 공통 설계 16장 → 통합 화면 12분야 중, 16→12는 실제 ID와 경로로 확인된다. 원목차→136의 이번 주제 대응은 감사자의 해석이며 개별 항목의 과거 작성 경로를 확정하지 않는다.

## 기준 자료와 방법

1. 사용자 제공 원목차를 복원하여 최하위 171개와 기존 136개를 양방향으로 대조했다.
2. 국립국어원 『2014년 표준 국어 문법 개발』(유현경 외)의 PDF 40–47쪽 분류 체계와 관련 선택 본문을 읽었다. 본문 확인 페이지는 manifest에 기록했다. 개발 단계 보고서이며 최신 완성판과 동일시하지 않는다.
3. 국립국어원 한국어기초사전 ‘새’ 항목으로 관형사/관형형의 설명 사례를 확인했다. 『한국어 표준 문법』(집문당)의 존재는 국립국어원 2025-04-23 안내로 확인했지만 전권을 읽었다고 주장하지 않는다.

모든 136개 행에 원래 역할·문헌 연결·기준 자료의 관련 영역·재검토 사항을 남겼다. 대응은 주제 수준이다. 한 기준 영역을 관련 항목에 연결한 것은 그 항목의 모든 조건·예외를 입증한 것이 아니다. 목차의 계층 차이 또는 문법 이론 차이를 바로 오류로 세지 않았다.

## 결과와 한계

- 136개는 개별 설계 125개와 묶음 창구 11개다. 문법 현상·조건·분석·검색·검사 책임이 함께 들어 있다. 동질적인 ‘문법 규칙 136개’로 설명하면 부정확하다.
- 출처가 있는 121개는 지정 방언 자료 D01–D07을 연결한다. 그중 15개는 같은 위키 계통 자료만 연결한다. 출처가 비어 있는 15개는 묶음 창구 11개와 처리 설계 4개다. 이 수치는 오류 개수나 정확도가 아니다.
- 일반 관형사·부사, 의존명사 일반 체계, 동사 외 단어 형성, 품사 판정, 문장 하위 구조, 시간 해석, 문장 유형 균형, 담화, 음운 범위, 정보 구조·분열문, 어휘상, 의문의 세부 유형, 부정 하위 유형, 어순 등을 **16개 검토 묶음**으로 정리했다. 빠진 규칙의 총수가 16이라는 뜻은 아니다.
- 분할 검토는 8개 묶음이다. 문법/프로그램 혼합과 집계 중첩은 확인되지만, 관형형/관형절/형용사 관형형의 구분은 책임 층위가 달라 중복 오류로 판정하지 않았다. 있다·없다/계사도 원래 계약은 동일시를 금지한다.
- 원목차 최하위 171개의 감사 분류: 당시 제외 15, 당시 보류·포괄 관련만 29, 관련 계약 있음 69, 세부 명세 부족 52, 전용 계약 없음 6. 이는 이번 분류 판단의 집계이며 구현률·검증률·문법 품질로 계산하지 않는다. 상위 계약에 관련 내용이 있다는 것과 하위 문법을 충분히 다룬다는 것은 다르다.

책 본문 전체의 정의·예외 대조, 독립 언어학 검토, 사람 평가, 새 전체 파이프라인 실행은 하지 않았다. 현재 목록으로 한국어 전체 문법의 충분성을 주장할 수 없다는 진단이며, 모두 폐기하거나 모든 문법서 항목을 KG에 추가하라는 결론도 아니다.

## 다음 작업과 종료 기준

현재 연구의 의미·높임 보존 목표에 필요한 공통 범위를 먼저 정한다. 우선 R01–R08 및 R12–R16의 기준 본문에서 정의·조건·예외를 확인하고 기존 항목 보완/신설/판단 보류를 나눈다. 담화·음성은 지원 범위와 입력 조건에 따라 결정한다. 선정 범위의 기준 항목이 모두 대응·보완·제외·보류 중 하나로 분류되고 근거 위치가 남는 것이 종료 기준이다.

그 뒤 판본을 고정하고 적용·비적용·모호한 예·결합 예로 KG 전수 검사를 설계한다. 모든 기존 노드를 지나가도 처음부터 빠진 문법은 검사할 수 없다. 반복 오류의 근거가 분류/조건 문제를 가리키면 예문만 늘리기보다 틀을 재검토한다.

검토자는 현재 대화의 AI 감사자 1명이며 독립 검토자는 사용하지 않았다. 사용자께 추가 승인 없이 이번 읽기·진단을 완료했다. 실제 KG 수정이나 연구 범위 확대는 이번에 수행하지 않았다.

# 카드 전달 비교 · 사용자 승인 정답 등록

사용자가 Claude 50개 번역을 현재 연구의 정답으로 승인했다. 원문과 Claude 출력을 바꾸지 않고 `data/derived_private/gyeongsang_reference50_20261030_v1/`에 버전과 승인 발언·해시를 기록했다. 정답은 허용 가능한 참조이며 다른 자연스러운 표현을 자동 오답으로 만들지 않는다. 과거 보고서의 당시 미승인 상태를 소급 수정하지 않는다.

## 이번에 바꾼 것

기존 50개를 모두 검토했다. 26개에서 이미 조회됐지만 최종 48개에 없던 관련 카드를 1~3개씩 넣었다. 총 53개 자리를 교체했다. 원문 분석·KG 조회 결과·카드 내용·생성 프롬프트·활용 검사는 그대로다. 차단 카드와 검토된 다른 문법 후보는 보호하고, 나머지 중 기존 점수가 낮은 카드를 같은 위치에서 교체했다.

26개는 기존/변경 전달 × Single/Multi, 총 104개 결과를 새로 실행한다. 나머지 23개는 전달 변경 없음, 1개는 기존 분석 실패다. 이 24개는 기존 결과만 표시하며 다시 실행한 것으로 세지 않는다.

완성 정답 문장은 Qwen에 전달하지 않는다. 다만 정답을 참고해 관련 카드를 골랐으므로 이는 원인 확인을 위한 실험이며, 새로운 입력에 대한 자동 검색기의 성능 평가가 아니다.

## 비교를 해석하는 방법

- 기존 전달도 같은 시간대에 재실행한다. 이전 실행의 서버 비결정성을 별도 관찰한다.
- 카드 수는 48개로 유지하지만 카드 길이와 토큰 수는 같지 않다.
- 카드를 추가하면서 다른 카드를 제거했으므로 교체 전체의 효과다. 추가 카드 단독 효과로 단정하지 않는다.
- 문장 변화·카드 선택·적용·완전 일치는 각각 기록하되 자연스러움 정확도로 표시하지 않는다.
- 선택되지 않은 이유는 모델이 적은 설명을 참고한다. 내부 계산의 인과 증명은 아니다.
- 현재 50개는 개발·회귀 자료다. 독립 최종 평가셋으로 주장하지 않는다.

## 실행과 산출물

- `run.py`: 고정 계획 작성, 캐시 분석 재사용, 기존 생성기 호출. `--execute`가 있어야 모델을 호출한다.
- `test_delivery.py`: 카드 교체의 보호·무변형·거부 조건 검사. 모델 호출 없음.
- `evaluate.py`: 저장된 요청·응답의 비교 및 50개 HTML 생성. 모델 호출 없음.
- `private/plan.json`: 실행 전에 고정한 50개 처분과 26개 교체 목록.
- `private/active_run.json`: 실제 Batch 및 4개 Run ID.
- `private/results.json`, `summary.json`: 원본 연결 및 재계산 가능한 비교 결과.
- `private/report.html`: 쉬운 비교 화면. 원시 문장·출력은 Git에서 제외한다.

모델 인증은 기존 로컬 설정 파일에서 읽으며 산출물에 복사하지 않는다. 실제 실행 원본은 `experiments/runs/`와 `experiments/batches/`에 별도로 보존한다. 이번 비교는 Neo4j 및 KG 내용을 수정하지 않는다.

| Single 기존 전달 | 15 | 11 | 0 |
| Single 변경 전달 | 10 | 15 | 1 |
| Multi 기존 전달 | 5 | 19 | 2 |

각 행은 26개다. 변경 수는 정확도가 아니다. 추가 카드가 선택된 입력은 Single/Multi 각 3개였고, 추가 카드로 인한 최종 변경 반영은 모두 0개다. 선택에는 유지/보류와 이후 실패한 계획도 포함한다.

104개 생성 조건의 실제 요청을 저장된 전달 목록과 대조했다. 같은 쌍의 원문·형태소·문법 분석·조회 결과·모델 지시·모델 설정을 확인했다. 카드 내용은 기존 값과 일치하며 48개가 유지되었다. 4개 Run의 입력·코드·KG 실행 전후 검사와 원본 해시 검증이 통과했다.

실제 모델 호출 116회, 토큰 827,947개, 일괄 실행 976.88초(약 16.3분). 신규 분석 호출 0회. 추가 카드 전달만으로 원하는 표현을 실현하지 못했으며, 카드 변환 방향·선택 기준과 편집 단위 실패 처리를 별도 검증 대상으로 남긴다. 원본 KG와 생성 코드는 수정하지 않았다.

기존 방식 재실행도 과거 출력과 Single 6개, Multi 2개가 다르다. 같은 설정의 단일 재실행만으로 출력 차이를 확정적 인과 효과나 일반 성능으로 주장하지 않는다.

### 기록 해석 정정

동결 Run의 `metrics.json`에 있는 `evaluation_note`는 기존 집계 함수의 “No gold labels...” 문구를 상속했다. 이번 실행 전 사용자 승인 정답 50개가 등록되어 있으므로 정답 존재 여부는 `reference_sha256`, 정답 manifest 및 이번 분석을 따른다. 다만 새 출력의 자연스러움 평가는 아직 없다. 동결 원본은 소급 수정하지 않았다.

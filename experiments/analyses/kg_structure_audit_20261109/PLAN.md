# ② 전체 KG 목록·구조 검사

연구 질문: 현재 KG의 어느 정보가 구조적으로 연결되고 실제 조건 조회기가 읽는가? 예문별 적용 검사 전에 누락·중복·명세/실행 불일치를 파악한다.

범위: 최신 실행 KG 1,491노드·5,037관계 전수 구조 검사, 별도 audit와의 복원/출처 연결 확인,56규칙·57분기·12모듈·26작업묶음 대응, 최근50 기록 재사용. 원본1,625/6,167과 이전 통합2,320/7,476은 계통·보존 비교 자료다. 전수 PDF 의미 재검증이나 새로운 자연어·Qwen 실행은 이번 범위가 아니다.

사용자 추가 확인: ‘전체 KG를 통과하는 예문 검사’는 이 목록 검사 다음 단계임을 설명했다. 분류/관리 노드 방문률 대신 실제 규칙·조건 분기의 적용/비적용/미확정 사례를 검사할 계획을 연결한다.

순서: 입력/코드 해시 고정 → 전체 항목/관계 상태 목록 → 실행 규칙·조건·출처 대응 검사 → 기존50에서 미관찰 이유 후보 → Orca 독립 검토 → 근거 대조/수정안/예문 검사 대상표 → 쉬운 보고서와 복구 기록.

종료: 모든 노드/관계와56규칙에 검사 상태가 있고, 확인된 문제마다 위치·근거·영향·수정안·다음 검증 방법이 연결된다. 미확인 의미/문헌/자연스러움은 명시한다. KG/운영 코드 수정은 하지 않는다. 근거 없는 분기를 추가하거나 모델 합의로 문헌을 확정하지 않는다.

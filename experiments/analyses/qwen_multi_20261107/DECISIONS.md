# 검토를 반영한 구현 결정

2026-11-07. 기존 Orca Claude와 Codex의 독립 검토 원문은 private 폴더의 design_review.md에 보존한다. 추가 로컬 GPT 기술검토는 기존 두 검토자의 검토로 세지 않는다.

## 채택한 구조

기본은 **구조 분석 → 의미·관계 분석 → 코드의 KG 조건 조회 → 선택과 전체 문장 작성 → 별도 호출 검토**다. Qwen 역할4개, 기본4호출, 구체적인 생성 오류가 있으면 작성자에게 최대1회 수정 요청하여 총5호출이다. 계획을 별도 워커로 분리하는 5역할/최대6호출은 `--separate-plan` 비교 옵션으로 남긴다. 최적 역할 수가 검증됐다는 뜻은 아니다.

Claude의 계획·작성 통합 권고를 채택했다. 동일 지식을 두 번 보내는 비용과 중간 요약에서의 누락 위험을 줄이고, 작성 응답에 후보별 적용/미적용 결정과 보존 항목을 먼저 받는다. Codex의 위치·규칙 결속 요구는 코드가 부여한 action_id로 구현한다. 실제 rule_id와 unit_id는 그 action에 고정되므로 모델이 새로운 규칙을 만드는 것은 허용하지 않는다.

## 최초 실행 조건과 종료

새 개발6문장: 과거 질문, 과거 평서, 요청, 금지, 안긴절+계사, 여러 문장의 높임·과거를 포함한다. 참조 번역은 입력하지 않는다. 기본 경로 최대30호출, 자동 전송 재시도0, 입력당 최대5호출. 3연속 기술 실패면 중단한다. 이전 200호출 프로그램과 별도로 기록한다.

원문 위치·ID·관계·호출상한·출처분리·초안보존 검사를 먼저 통과해야 호출한다. 연결 성공은 자연스러움 개선이 아니다. 반복되는 분석/생성 결함이 있으면 50건으로 확대하지 않고 처음 실패한 단계와 해결안을 남긴다. 기존 Qwen 단일/동일호출 비분업 대조는 이 구현의 효과를 검증할 다음 실험이다.


### 실제 구현 교차검토 반영

Claude B1~B3: 단위별 형태 표기 계약, 명사 재귀/의문 구별, 절 소속의 무단 덮어쓰기 방지를 반영했다. Codex I01~I03: 모델이 낸 형태 목록과 선어말 요약의 모순, 조회 실패와 모델 실패의 분리, 검토 응답 수신과 인용 근거 유효성 분리를 반영했다. 문법 판단을 코드로 확정하지 않으며 모순되는 값은 보존하고 관련 후보를 보류한다. 이것은 새 방언 규칙 추가가 아니다.

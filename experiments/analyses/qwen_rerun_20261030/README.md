## 확인한 문제와 다음 범위

공통 분석의 높임 오판, 이번에 쓰지 않는 지역 설정 요구, 관형·인용 연결 손실, 회상 성분 손실, 의문문 하위 유형 미검사, 활용형에 내용어 추가, 응답 형식 실패, 파생 접사 보존 누락, 조사 의미 불일치가 관찰됐다. 각각의 실제 근거는 보고서에 연결했다.

다음 제안은 생성용 조건 정제 → 공통 문법 분석·검사 보완 → 단계별 원인 확인 실험 → 전체 회귀 비교다. 이 제안에 따른 코드 수정·추가 모델 호출은 이번 실행에 포함하지 않았다. 두 외부 Reviewer의 이번 실제 출력 재검토도 아직 수행하지 않았다.

## 재현

기존 `tools/run_kg_cards.py`에 project, inputs(v2), 로컬 credentials 파일, 로컬 qwen-config, `--phase regression`을 전달한다. 다시 실행하면 새 Batch/Run ID가 생기며 모델을 호출한다. 정확한 실행 코드/프롬프트는 각 run의 `code_snapshot`, `config.json`, 해시 파일에 보존되어 있다. 현재 작업 디렉터리는 이후 바뀔 수 있으므로 그 스냅샷을 기준으로 한다.

추가 모델 호출 없이 이 보고서만 재계산:

```powershell
python experiments/analyses/qwen_rerun_20261030/compare_results.py
```

원문·개별 출력은 `private/`에 보존하여 Git에서 제외한다. 원격 GPU 사용량·원화 비용은 측정하지 않았다.

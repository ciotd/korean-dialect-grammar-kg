# 분석 6곳 보완과 조건 근거 연결

이 작업은 새 문법을 늘리는 단계가 아니다. 기존 50문장 중 분석 보류로 표시된 6곳을 대조하고, 모델 질문·조회 상태·근거 연결을 보완했다.

## 결과를 읽는 순서

1. `private/report.html`: 쉬운 설명, 6곳 진단, 50문장 전후 비교.
2. `private/reviewers/`: 기존 Orca Codex·Claude 검토자의 실제 지시문과 의견.
3. `private/summary.json`, `private/all_targets.json`: 수치와 위치별 원본 연결.

## 실제 실행과 결과

| 실행 | 모델 호출 | 결과 | 의미 |
|---|---:|---|---|
| followup_diagnostic / `20261103T093319695026Z` | Qwen 분석 12회 | 9조합·1분석보류·2미지원 | 별도 개발용 연결 검사 |
| followup50 / `20261103T093451123726Z` | Qwen 분석 62회 | 15문장·16위치 조합 | 기존50건 새 답변. 검토에서 검사 누락 2곳 발견 |
| checked_replay50 / `20261103T094439414985Z` | 0회, 위 답변62개 재사용 | **13문장·14위치 조합, 2위치 보류, 46위치 미지원** | 동일 답변으로 검사 누락 수정 효과만 확인 |

Qwen 생성 API는 호출하지 않았다. 승인한 방식대로 Kiwi 조합기가 최종 문장을 만들었다. 변환 수는 자연스러움 점수가 아니다.

`사 온 사과 먹어 봤어?`의 `봤어→봤나`가 추가로 연결됐다. 다만 Qwen은 `사→온`을 auxiliary가 아닌 linked로 답했다. 구조 통과를 의미 분석의 정답으로 발표하지 않는다. 처음 채팅에서 정확한 연결이 된 것처럼 설명한 부분은 이후 정정했다.

## 실제 수정

- `runtime.py`: 경계 어절별 고정 질문, EC/ETM/ETN별 후보, unknown 유지. 지원 범위와 분석 문제 분리. 비말단 복수 경계 누락 탐지.
- `build_provenance.py`: 조건별 근거·해석·구현 선택을 구별한 KG r3.
- `refine_provenance.py`: 검토 후 인용 문맥·입력/출력 역할·높임 해석 한계를 보완한 r4. 실행 허용값 변화 없음.
- `test_runtime.py`: 12개 검사. 과거 사례를 수작업으로 수정한 검사는 실제 모델 성능과 구분.
- `replay_checked.py`: 원래 요청과 현재 요청이 동일함을 검사한 뒤 저장된 답변 재사용. 새 모델 호출 없음.
- 기존 `research_loop_20261103/run.py`: followup 경로와 코드 동결 연결.
- 기존 `kg_pipeline/io.py`: 모델 JSON의 중복 키를 조용히 덮지 않고 오류로 기록.

## KG 버전과 재현

- Qwen 새 실행: r3, 141노드·292관계.
- 근거 보완 후: r4, 146노드·306관계. 같은62답변의 후보·준비상태가 동일함을 먼저 확인했다.
- 검사 누락 수정은 KG 변경과 별도이다. 그 뒤 동일 답변 재검사에서 2위치를 보류했다.
- 기존 r2와 질문 KG, 과거 실행, 확정 입력 원문은 보존했다. Neo4j 실DB에 r4를 적재하지 않았다.
- 공통척추·12모듈 전체 정제가 완료됐다는 뜻이 아니다. 실행 문법은 기존9용법 그대로다.

실행 재현: 저장소 루트에서 프로젝트 Python으로 `experiments/analyses/research_loop_20261103/run.py followup50` 실행. 현재 설정은 r4와 수정 검사기를 사용한다. 과거 r3 실행은 해당 run의 코드·KG 동결 사본을 참조한다.

모델 호출 없이 검사만: `experiments/analyses/condition_followup_20261103/test_runtime.py`.
같은 Qwen 답변 재검사: `experiments/analyses/condition_followup_20261103/replay_checked.py` — 새로운 run_id로 기록된다.

## 다음 단계

우선 한 어절 안 여러 경계를 각각 표현하는 분석 계약을 설계한다. 현재 보류한 두 위치의 연결 누락을 해결하고, `사→온` 같은 의미 관계도 함께 확인한다. `계세요` 형태 분석 충돌은 별도 진단한다. 이후 명사+이다 평서·높임 등 다음 문법 묶음을 합의하여 확장한다.

이번에 보류된 출력이 실제로 부자연스럽다는 판정은 하지 않았다. 단지 불완전한 연결을 완전한 분석으로 기록하던 오류를 바로잡았다.

### 검토 후 출처 표기 보충
D02 PDF75의 EV_DECL_CLASSIFICATION_WIDTH는 각주70이 표준국어대사전을 재인용한 내용이다. D02 PDF203의 EV_DECL_INPUT_EO 빈도 행은 표48이고, 다른 입력형 목록은 표47이다. 실행에 사용한 동결 그래프는 다시 쓰지 않았으며 이 표기 보충을 기록한다. 두 검토자의 최종 확인과 의견별 처리는 private/reviewer_resolution.json에 있다.

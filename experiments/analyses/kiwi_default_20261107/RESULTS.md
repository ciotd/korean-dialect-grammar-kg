# 결과와 다음 결정 · 2026-11-07

## 결론

Kiwi를 기본 형태 분석으로 전환했다. 누락·미확정 기록, 금지/요청·본/보조 연결, 겸양 보존을 보완하고 새12문장으로 두 차례 비교했다. 요청 구성의 지식 도달과 겸양 보존 사례는 개선됐으나, 존댓말 손실과 새로운 보조 의미 오류가 남았다. **사전 종료 기준에 따라50건 재실험은 실행하지 않았다.**

Kiwi 기본 전환과 보완 후보의 품질 채택을 구별한다. 현재 CLI의 첫 보완(B1)은 개발 기본값이며 품질 검증 완료판이 아니다. 추가 질문 형식(B2)은 명시 옵션으로 보존하고 자동 기본 승격하지 않았다. Qwen은 계속 최종 문장 작성자다. 자동 재분석/재작성은0회다.

## 다음 작업과 종료 기준

1. **모델 호출 없이 조건 역할부터 점검:** 해예 규칙의 주체 높임이 선택 조건인지 보존 항목인지, 금지 보조 분류가 실제로 어떤 규칙을 여는지 확인한다. 종료 결과는 규칙별 유지/수정 근거와 영향표다. 근거가 없으면 미확정으로 보류한다.
2. **조건 전달과 생성 능력을 분리:** 같은 원문·분석·생성 지시에서 필요한 KG 규칙 전달만 고정한 진단을 설계한다. 완성 방언 정답은 넣지 않는다. 전달해도 손실이 반복되면 조회만 계속 고치는 접근을 멈추고 생성 역할/모델 비교를 검토한다.
3. **회복 확인 후50건:** 새로운 개발 입력의 연결·보존까지 확인한 뒤50건 전체 연결을 실행한다. 실패하면 후보로 남기고 범위를 바꾸기 전 근거와 대안을 보고한다.

이번에 합의한 추가 보완 한 묶음은 종료했다. 위 다음 작업의 실제 수정·Qwen 호출은 이번 결과에 포함하지 않는다. 전체 문법 정제·미지원 범위 확장·일반 검색/조건표/그래프 비교·독립 최종평가 계획도 남아 있다.

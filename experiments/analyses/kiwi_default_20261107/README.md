# Kiwi 기본 형태 분석과 문법 연결 보완 · 2026-11-07

## 무엇을 하는 경로인가

Kiwi가 원문을 형태소로 나눈다. Qwen은 절 범위와 문법 의미·관계를 판단한다. 코드는 그 값으로 기존 KG의 조건과 연결을 조회한다. 마지막 작성자 Qwen이 문장 전체를 생성한다. 별도 Qwen 검토자는 문제를 기록하며, 이번 실험에서는 자동으로 문장을 다시 쓰게 하지 않는다. 이전 검토의 오탐이 출력을 악화시킨 기록이 있기 때문이다.

- 기본 실행기: `tools/run_qwen_multi.py`의 `analysis-backend=kiwi`. Qwen 형태 분석 비교는 `--analysis-backend qwen`으로 보존한다.
- 공통 연결: `src/kg_pipeline/kiwi_default.py`.
- 실제 실행·상한·시간·이력 기록: `tools/run_kiwi_default.py`.
- [역할별 실제 프롬프트와 선택 이유](prompts.md).

## 보완한 것과 고정한 것

| 구분 | 내용 |
|---|---|
| 누락 | Kiwi에 관찰된 용언·연결어미가 조회 단위에 없는지 기록. 누락을 자동 정답 단위로 만들지는 않음 |
| 미확정 | 해석 못한 선어말을 과거 없음으로 바꾸지 않음. 없음과 모름을 구별 |
| 의미·연결 | 금지/요청을 구별해 묻고 실제 본·보조 후보 ID를 제시. 추가 후보에서는 구성별 명시표를 요구 |
| 겸양 | 저/제/저희를 나/내로 바꾸지 않도록 전달. 복원된 조사 기본형과 원문 글자를 구분 |
| 고정 | KG 문법 조건·문헌 사실·방언 정답 저장은 변경하지 않음. Qwen이 최종 작성 |

새12문장은 이번 개발 점검용이다. 같은12문장을 재실행한 것이 추가12개의 새 데이터는 아니다. 최초에는 옛 방식과 첫 보완을 비교하고, 후속에서는 첫 보완을 다시 실행하면서 의미 질문 형식 보완과 비교한다. 후속에서는 첫 실행의 형태·절 구획을 그대로 읽는다. 첫 보완의 최초/반복 결과도 공개한다.

실행 기록은 `latest_development.json`에 연결된다. 호출 원문·출력·입력·KG·코드·프롬프트·해시와 비용은 고유 run 폴더에 보존하며, 과거 실행을 덮어쓰지 않는다. 체크포인트는 복구용이며 번역 품질 인증이 아니다. 실험 결과와50건 진행 여부는 완료 후 `RESULTS.md`에 확정한다.

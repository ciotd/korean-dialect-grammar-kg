## 무엇을 비교하는가

입력은 확정 회귀 문장 **50개**다. 이전/새 카드 × Single/Multi의 네 조건으로 비교하므로 결과 기록은 **200개**다. 데이터셋이 200문장으로 늘어난 것이 아니다. 기존 분석 실패 QUAL002는 네 조건에서 그대로 실패로 기록하고, 나머지 49개에서 생성 모델을 호출한다.

같은 시간대에 이전 카드도 재실행한다. 26개는 직전 전달 실험의 promoted 목록, 나머지는 원래 목록을 사용한다. 각 입력의 v2/v3에는 같은 분석·카드 ID·순서·형태 목록을 전달한다. 새 KG 조회와 새 문장 분석은 없다. 카드 설명·조건과 그 내용에서 계산한 요청 식별값만 달라진다.

새 카드 버전: `kg_cards_20261030_v3`. 이전 카드 버전: `kg_cards_20261028_v2`. 카드 관리 정보 정리와 10개 변환 방향 보완을 함께 비교하므로 두 변경의 효과를 분리해서 주장하지 않는다. 반복은 조건당 1회이며, 공유 서버의 부하와 비결정성을 완전히 배제하지 못한다.

## 재현과 기록

- `run.py`: 사전 동결·실행·실시간 진행·Run 등록. 실행할 때마다 새 Batch/Run ID를 만든다.
- `evaluate.py`: 저장된 실제 요청과 결과에서 비교 화면·통계를 생성한다. 모델을 호출하지 않는다.
- `private/plan.json`: 입력별 원본 분석·목록 경로와 해시. 이미 동결한 자료가 달라지면 실행을 거부한다.
- `private/active_run.json`: 이번 실행 묶음 및 네 Run ID.
- `private/cases.json`, `private/summary.json`: 입력별 비교와 집계. 실행 중에는 미완료 상태를 표시한다.
- `private/diagnostic_checks.json`: 실제 출력과 별개인 Codex 오프라인 검사. 모델 호출 없이 카드의 문자 교체 지시대로 만든 후보도 기존 검사가 통과하는지 확인한다.

각 Run에는 요청·응답·형태소 분석·조회·실제 전달 카드·수정 계획·검사·최종 출력과 코드 스냅샷을 보존한다. 새 실행의 비용에서 과거 분석 호출과 시간을 제외한다. 실패와 보류도 삭제하지 않는다.

```powershell
# 자료 고정 및 무호출 검사
python experiments/analyses/card_content_experiment_20261030/run.py
# Qwen 실제 호출: 새 실험 실행을 승인한 범위에서만 사용
python experiments/analyses/card_content_experiment_20261030/run.py --execute
# 보고서 재집계만 수행
python experiments/analyses/card_content_experiment_20261030/evaluate.py
```

이번 실행은 사용자 요청 “카드 새 버전으로 바꿔서 실험 진행”에 따른다. 신규 출력의 자연스러움에 대한 사람 점수는 아직 없다. 문장 변경 수·카드 적용 수·정답 문자열 일치 수를 자연스러움 정확도로 사용하지 않는다. 승인된 참조 표현은 카드 작성과 이전 전달 실험에서 이미 참고했으므로 이 50개를 독립 평가셋으로 주장하지 않는다.

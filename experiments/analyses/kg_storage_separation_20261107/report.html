5. 완료한 일과 다음 일

완료: 백업, 새 KG 파일, 출처·검토 분리, 조회기 연결, 전체 복원 검사, 기존 조건 및 실제 분석 기록 재생을 마쳤습니다. 통합 실행기에서 KG 경로를 따로 지정하지 않으면 새 저장 버전을 읽습니다. 이전 버전으로 비교하려면 해당 경로를 명시하면 됩니다. 생성 모델은 출처 기록 파일을 읽지 않습니다. 필요한 경우 연구자가 ID로 따로 조회합니다.

이번에 하지 않은 일: 문법의 옳고 그름을 새로 판정하거나 규칙 범위를 확장하지 않았고, Qwen을 다시 호출하지 않았습니다. Neo4j에 남아 있는 과거 데이터도 덮어쓰지 않았습니다. 따라서 방언 자연스러움이나 생성 속도가 개선됐다고 말할 수 없습니다.

다음: 이 새 저장 형식을 기준으로 전체 지식의 의미·조건 검토를 이어갑니다. 출처가 필요할 때만 별도 기록을 열면 됩니다. 이후 생성 비교에서는 KG 버전과 전달 길이를 고정하여 정리 효과와 문법 수정 효과를 구분합니다. 조건·조회가 달라지는 문제가 발견되면 새 버전을 보류하고 백업 버전을 사용합니다.

검토 역할: 이번 작업은 자동 검증과 리드의 코드 점검으로 확인했습니다. 외부 Claude·Codex 검토자에게 새 자료를 보내거나 독립 검토를 받았다고 주장하지 않습니다. 사용자에게 새 문법 판단이나 추가 승인을 요청할 항목은 없습니다.

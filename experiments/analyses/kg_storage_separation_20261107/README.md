## 비교 통제와 결과 해석

- 같은 저장 분석·조건·조회 순서·문자 제한(기존 24,000자 정책)을 사용했다. 새 분석값/정답/언어 지식은 넣지 않았다.
- 99개 기록은 고유 문장 79개이며 재실행 기록을 포함한다. 기존 100개 입력 기록 중 1개는 분석 파일이 없어 재생하지 못했다. 실패를 성공으로 집계하지 않는다.
- 조회 판정과 제한 없는 문법 전달 내용은 전후 일치한다. 같은 길이 제한에서도 적용 후보 규칙 묶음은 변하지 않았다. 미정제 참고 항목 전달은 2기록에서 달라졌다. 원인은 출처 정보를 빼면서 여유가 생겼기 때문이다.
- 실행 그래프의 동일 직렬화 기준 크기는 5,973,225바이트 → 3,260,189바이트. 길이 제한 없는 전체 전달문은 1,327,479자 → 976,651자. 문자/바이트이지 모델 토큰·자연스러움·속도 점수가 아니다.
- 새 단위 검사와 기존 통합 검사 결과는 `private/`에 보존한다. 처음 실행기 검사에서 새 의존 파일을 임시 시험 폴더에 복사하지 않아 실패했으며, 시험 준비 목록을 수정했다. 실제 Qwen 실패가 아니다.
- 혼합된 문법 설명은 통째로 지우지 않았다. 현재 실행에 쓰지 않는 의미 정보도 검색 가능한 기존 지식에 유지했다. 전체 지식의 의미 재검토 완료로 해석하지 않는다.

## 재현 및 산출물

```powershell
python tools/separate_kg_storage.py
python -m unittest discover -s tests -p test_separated_graph.py -v
python -m unittest discover -s tests -p "test_integrated*.py" -v
```

`latest.json`이 가리키는 `private/<고유 시각>/`에는 `before_graph.json`, 코드 사본, 조건 재생 결과, 입력별 전달 전후 비교, 요약, HTML이 있다. 새 KG 폴더의 `audit.json`에는 모든 이동 항목·변경 전 속성·변경 위치·복원 해시가 있다. 실패한 실행도 해당 고유 폴더에 남긴다.

검사 통과 조건은 원본 바이트 백업 일치, 원본 JSON 완전 복원, 비문헌 관계·규칙 조건 보존, 동일 입력 조회와 언어 지시 동등성이다. 생성 품질 검증은 이 종료 조건에 포함하지 않는다. 이후 전체 지식·문법 조건 검토는 이 버전을 바탕으로 이어가며, 조회/조건 변화가 발견되면 원인을 확인할 때까지 새 버전 사용을 보류한다.

외부 검토자 호출 없이 리드의 구현·코드 점검과 자동 검사를 수행했다. 새 모델 실험·문헌 재해석·사람의 언어 판단은 요청하지 않았다. 로컬 Git 체크포인트와 비공개 파일 백업은 별도이며, 이번 작업에는 GitHub 푸시와 Neo4j DB 교체가 포함되지 않는다. 같은 디스크의 사본은 디스크 고장 대비 외부 백업을 대신하지 않는다.

보고서 HTML은 만들었으나, 이번 도구의 로컬 `file:` URL 제한으로 내장 브라우저 시각 점검은 하지 못했다. HTML 내용·숫자·링크는 파일 검사로 확인한다.

# 두 검토 의견의 대조 결과

기존 Orca Codex(GPT-6-Astra high)와 Claude(Opus 5.5)가 지정 자료를 독립 검토했다. 두 결과 모두 도착했다. 문헌 전체 재독이나 자연스러움 평가를 수행한 것은 아니다.

## 반영한 것

- 문장 변경 17건과 위치 변경 18곳을 분리했다. LONG001 W12는 지시를 받았으나 그대로였다.
- 미전달의 대표 경로와 겹치는 분석 미확정을 분리했다. 대표 경로가 분석 미확정이 아닌 4곳에도 미확정 특징이 남아 있었다.
- 네 구성 모두 범위 밖이면 기록의 첫 구성 ID를 실제 적용 구성처럼 표시하지 않는다. 원본 ID는 보존하고 표시용 값을 별도 저장했다.
- 조회 248개(62위치×4구성), 원본 1,023파일, 실제 전달·원시 응답의 일치 확인을 근거로 삼았다.
- 종결어미가 있는 62어절에 대한 점검이다. 그 밖의 연결어미·관형절·조사 태그 어절 193회는 문맥에 포함될 수 있지만 독립 수정 대상은 아니다. 193은 규칙 개수가 아니다.

## 리드가 추가로 원시 응답을 대조한 것

- ADVCE002A의 Qwen 설명은 ‘계시다로 주체 높임’이다. 그런데 실제 조회용 형태 분석은 계/NNG+이/VCP+세요/EF였다. 따라서 이를 Qwen이 계시다를 모른다고만 설명하거나, 단순히 KG에 규칙이 없다고 설명하는 것은 부정확하다.
- ADVCE008A의 ‘상대의 행동을 요구하거나 재촉함’과 ‘주체를 높임’, LONG004 W16의 ‘함께 행동하자고 제안함’과 ‘주체를 높임’은 원시 Qwen 분석 응답에 이미 존재한다. 후처리만의 문제는 아니다. 같은 종결형이라도 전체 문맥은 대조해야 하며, 표면형만 같다는 이유로 정답 판단을 고정하지 않는다.
- DEV026의 경계 unknown도 원시 Qwen 응답에 있다. 이 경계를 확인하지 않고도 주절 종결을 바꿀 수 있는지는 별도 가설이다.

## 그대로 채택하지 않은 제안

- ‘계사 앞 명사가 한 음절이면 의심’, ‘시/세/셔라는 글자가 있는데 선어말이 없으면 차단’ 같은 규칙은 과잉 차단 위험이 있다. 새 일반 규칙으로 추가하지 않았다. 분석 근거 사이의 불일치를 드러내는 검토 사례로만 남긴다.
- 미지원 곳의 실제 필요한 값을 모두 unknown으로 바꾸는 작업은 하지 않았다. 원시 기록을 보존하고 오류 후보 표시만 한다.
- Claude가 제안한 평서 결합 설명 변경은 이전 r8/r9·prefix·시스템 지시 비교와 중복될 수 있다. 단순 재시행을 확정하지 않았다. ②에서 이전 비교와 다른 가설이 있는지 먼저 확인한다.
- 참고 노트 18회 생략은 사실이나, 전부 전달하면 좋아진다는 근거는 없다. 다른 화계·지역 용법을 섞는 부작용도 가능하다. 실제 선택에 필요한 정보인지 먼저 정한다.
- ‘어딘고’의 자동 경고는 자연스러움의 최종 판정이 아니다. 모델이 반환한 전체 문장은 원시 기록 그대로다. 해당 축약의 허용 여부는 원문·화자 검토 없이 확정하지 않았다.

## 종료 판정

① 완료: 저장된 50입력·62종결 위치의 제한/전달/원시 출력 연결과 두 검토자의 대조를 마쳤다. 확인된 것은 실행 경로와 오류 위치이며, 모든 언어학적 원인이나 개선 효과를 확정한 것은 아니다. 새 Qwen 호출·KG·운영 코드 변경은 없다. 다음은 ② 비교 조건 확정이다.

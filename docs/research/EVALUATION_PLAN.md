**2026-10-23 관리 정책 갱신:** 아래 데이터 분리 절은 초기 제안이다. 이후 확정한 `standard_inputs_50_20261023_v1` 50건은 첫 평가를 완료했고, 앞으로 평가 기준으로 보존하며 개발·튜닝 입력과 분리한다. 과거 대화·설계 노출이 있어 미공개 독립 평가셋으로 취급하지 않는다. DEV 등 ID 접두사만으로 현재 용도를 판단하지 않는다. 현행 규칙은 [관리 시스템](RESEARCH_MANAGEMENT.md)을 따른다.

상태: 제안. 표본수·평가 화자·최소 실용 차이·분석 계획·임계치는 아직 확정하지 않았다. 이 파일은 실행 완료 또는 사전등록 증명서가 아니다.

## 1. 데이터 분리

기존 DEV/LONG/NEW/ADVCE와 사용자20개는 개발 회귀 자료다. 독립 새 문장은 수정·프롬프트 선택에 사용하지 않고 따로 확보한다. 자연 발화와 연구자 도전 문장을 구별하고 조사·높임·관형·인용·의도·부정·시제/상·어휘 의미 층을 기록한다. 자연분포 대표성 평가와 실패 유형 도전 평가를 별도로 보고한다. AI-Hub를 사용할 경우 구축·검색·튜닝에 노출 여부와 라이선스를 먼저 확인한다.

## 2. 비교 실험

| 대비 | 통제할 것 | 식별할 질문 |
|---|---|---|
| 분석 보조 없음 / 공통 분석 있음 | 외부 지식·모델·설정 | 분석 보조 효과 |
| 공통 분석+지식 없음 / 텍스트 검색 / KG 선택 | 같은 근거 풀·분석·모델·설정·평가 입력 | 근거 선택 방식의 시스템 효과 |
| 동일 후보의 원본 전달 / 구간 계획 전달 | 후보·조건·범위·예문·지시의 정보 차이 기록 | 전달 방식 효과 |
| 필요한 관계 있음 / 해당 관계만 제거 | 동일 KG 복사본·시작점·예산, 실제 패킷 차이 | 관계의 국소 기여 |
| 자동 분석 / 검토된 분석 | 다른 층 고정 | 분석 오류의 상한 진단 |
| 현재 후보 / 검토된 최소 후보·활용 계획 | 모델·설정·원문·보존 의무 | 생성기와 후보 경쟁 진단 |

동일 후보 전달 대비와 검색 방식 대비를 혼합하지 않는다. 정보량을 완전히 맞추지 못하면 차이를 보고하고 해석을 제한한다. 모델·KG·검색 인덱스·전체 prompt·후처리·재시도·예산·시드·체크포인트를 동결한다. 여러 seed 및 동일 요청 반복은 파일럿 비용·분산으로 횟수를 정하며 가장 좋은 출력만 선택하지 않는다.

## 3. 분리할 평가값

- 근거 품질: 원문이 진술을 뒷받침하는가, 조건·범위·예외가 충실한가. 평가 단위와 독립 표본 추출을 명시한다.
- 분석 정확성: 절·서술어·의문종류·높임·시제/상·부정·인용·관형의 판정. 형식 검증 통과율과 별도다.
- 조회: 필요한 근거의 도달률, 잘못된 후보 노출, 조건unknown/배제, 선택 예산에 의한 누락. 필요한 근거를 먼저 주석해야 분모를 정할 수 있다.
- 실현: 선택한 후보가 대상 구간에서 올바르게 적용됐는가. 적절한 보존·동의 변형을 허용하며 단순 문자열 포함으로 채점하지 않는다.
- 보존: 명제 의미·겸양·청자/주체높임·시제/상·부정·인용 구조. 입력과 동일한 출력도 맥락에 따라 타당할 수 있다.
- 자연스러움: 해당 지역·화자·상황에 맞는 방언 화자 평가. 원문·참고 출력·조건명을 가리고 제시 순서를 무작위화한다.
- 비용: 입력/출력 토큰, 분석·생성·재시도 횟수, 지연·작성/검토 비용. 문자 수를 토큰 수로 대체하지 않는다.

사람 점수는 실제 평가자가 작성한다. 모델 judge는 보조로 표시하고 검증된 판별 범위를 넘어 화자 정답으로 쓰지 않는다. 불일치와 평가자간 신뢰도·해결 절차를 기록한다.

## 4. 분석과 실패 보고

짝지은 입력 단위를 사용하고 같은 발화 내 여러 문장을 독립 표본으로 무조건 세지 않는다. 효과 크기와 불확실성 구간을 보고하고, 표본 구성·결측·실패·다중 대비 처리·중단 기준을 결과 확인 전에 정한다. 주요 지표를 결과 확인 뒤 유리한 지표로 교체하지 않는다. 개발 중 수정이 생기면 변경 이유와 새 평가 범위를 기록한다.

경고0개, 출력변경, 표지증가, 페이지reviewed, 테스트passed는 품질 통과 판정이 아니다. 독립 평가가 없으면 탐색적 사례 분석으로 보고한다.

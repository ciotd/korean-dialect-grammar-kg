# 미해결 질문과 검증 방법

| ID | 질문 | 필요한 근거·진단 | 현재 상태 |
|---|---|---|---|
| Q001 | 목록형 진술과 적용형 규칙을 어떤 단위로 구별할까 | 실제 용법·결합·조건·반례의 독립 판정 | 미정 |
| Q002 | 인용/의도·관형·시제/상/부정의 범위를 어떻게 표현할까 | 구성 자리·순서·내외절 결속을 포함한 작은 설계 대조 | 기존 표현이 불완전 |
| Q003 | 자유 서술 제약을 얼마나 구조화할 수 있을까 | 원문에 명시된 조건과 해석 조건 분리, unknown 처리 | 미정 |
| Q004 | 후보가 도달해도 미적용되는 원인은 무엇일까 | DEV025/NEW007/DEV027 유형에서 최소 계획·후보 제거·전달 형식 대비 | 원인 미확정 |
| Q005 | 근거가 없는 활용형을 어떻게 처리할까 | 문헌 확인형, 제한 조합, 생성 추정을 분리해 평가 | 미정 |
| Q006 | 화용적 높임·겸양을 검사할 수 있을까 | 저/제·청자/주체높임·인용 화자 별도 주석과 화자 평가 | 현 검사 누락 있음 |
| Q007 | KG 관계의 추가 효과를 식별할 입력은 충분한가 | 실제 다른 지식/경로가 전달되는 대비와 관계 제거 검증 | 이전 비교는 노출 적음 |
| Q008 | 현대 자연스러움의 대상 지역·연령·상황은 무엇인가 | 문헌 시대와 목표 화자를 분리한 평가 모집·절차 | 확정 안 됨 |
| Q009 | 원본 PDF와 표·각주를 독립 검토할 수 있는가 | 합법적 로컬 접근·파일 해시·의미 대조 | 이번 이관에서 미수행 |
| Q010 | 모델 체크포인트·양자화·서버 변동을 고정할 수 있는가 | 실제 모델 revision/weights hash/엔진·환경 기록 | 과거 model ID만으로 불충분 |
| Q011 | 최종 표본수와 판정 임계치는 무엇인가 | 파일럿 분산, 독립 단위, 최소 실용 차이·사전 분석 계획 | 미정 |
| Q012 | 외부 평가 피드백을 어디까지 자동 반영할까 | 제안→원문 대조→반례→검증→승인 상태의 분리 | 구현하지 않음 |
| Q013 | 다른 한국어 방언으로 확장할 것인가 | 방언별 자료·라이선스·범위·독립 평가 | 현재 경상도만 |

분석 결과가 참인지, 조회가 적절한지, 생성기가 적용했는지, 최종 문장이 자연스러운지는 별도로 검증한다. 어느 하나의 실패로 다른 층의 일반적 불가능을 확정하지 않는다.

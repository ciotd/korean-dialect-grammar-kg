## D029 · 검색과 문장 적용의 분리 (2026-10-25)

이전 실행층은 실제 조회를 17개 SourceAtom으로 제한했다. 721개 문헌 항목과 125개 공통 개념을 모두 주소로 조회할 수 있도록 하고, 문장별 모듈 검색에서 활성화/지역 승인 상태를 제외했다. 원문 위치와 변환 코드가 있는 17개 연산자는 별도 적용 후보로 관리한다. 출처·문헌 범위·검토 상태는 ID별 보존하며 원본 Neo4j를 수정하지 않는다.

## D030 · 비용과 품질을 구별한 대조 (2026-10-25)

50건은 회귀용이다. 새 12건은 모델 실행 전에 고정하되 작성된 편의 표본임을 명시한다. 같은 모델/KG/연산자로 Single과 Planner–Worker를 비교한다. Kiwi 분석 대조는 같은 요청에서 토큰 정보만 추가한다. 정확도·자연스러움 정답은 없으므로 자동 통과 수를 품질 점수로 바꾸지 않는다. 추가 조회의 실익과 문헌을 부정하는 모델 판단도 오류 분석에 포함한다. 상세 근거는 SEARCH_EXECUTION_20261025.md와 실험 원본에 있다.

## D031 · 말단 지식과 문장 수정 계획을 분리 (2026-10-28)

사용자 요청에 따라 D025/D029의 17개 Python 연산자 제한을 새 실행기에서 제거한다. 재사용할 지식은 7필드 카드로, 현재 입력의 수정은 원문 어절 ID·사용 카드·지시·생성 어절로 구별한다. 원본 Neo4j의 ID와 연결을 조회하고 카드 파일을 같은 ID로 결합한다. 단일 규칙마다 함수를 만드는 대안보다 유지보수와 범위 확장에 유리하지만, 조건의 의미 판단과 활용의 정확성은 모델 오류에 노출된다. 무조건적인 적용·품질 보증으로 표현하지 않는다.

## D032 · 공통 분석을 공유한 Single/Multi (2026-10-28)

같은 입력의 Kiwi·Qwen 분석 및 카드 선별 결과를 한 번 생성해 두 조건에 동일하게 전달한다. 조회 후 Single은 계획과 활용을 한 호출, Multi는 Planner와 Worker 두 호출로 수행한다. Qwen이 생성한 어절을 공통 코드가 원문에 조립한다. 방식별 비용에는 공통 분석을 한 번 포함하고, 실제 배치 비용에서는 공유분을 한 번만 센다. 모델 checkpoint·GPU 부하 등 서버가 공개하지 않는 정보는 측정한 것으로 쓰지 않는다.

## D033 · 사람 평가의 저장과 해석 (2026-10-28)

원래 50건에서 이전 Single·새 Single·새 Multi를 문장별 A/B/C로 섞는다. 자연스러움 1~5와 의미·시제·높임 보존 여부를 사람이 입력한다. 원본 실행을 수정하지 않고 별도 평가 파일과 저장 이력을 만든다. 미평가·출력 없음은 0점으로 계산하지 않는다. 한 평가자의 회귀 문장 평가를 경상도 전역의 일반 성능으로 확대하지 않는다. 방법표는 서버의 파일 공개 허용 목록에서 제외한다.

## 2026-10-30 · 카드 내용 v3와 선별의 분리

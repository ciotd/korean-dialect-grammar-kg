## 관찰된 문제

1. 모델이 원문 표면형과 기저 형태를 혼동해 입력에 없는 anchor를 반환하거나, 단위를 잘못된 절에 연결했다. 15개 입력은 생성 전에 중단했다.
2. 형식 검사를 통과한 분석에도 오류가 있다. DEV003·DEV005의 완료 보조구성 오판이 관련 근거 선택으로 전파되었다. 생성 모델은 부적합하다고 보고 변경을 보류했다. 같은 모델의 재판단을 독립 검증으로 보지는 않는다.
3. 현재 구현은 직접 대조 진술 29개 중 구현한 조건을 사용한다. 전체 721개 항목의 범용 규칙 엔진이 아니다. 근거의 제한된 지원 범위와 모델 분석 오류를 분리해 보완해야 한다.
4. 정확한 ID를 사용했다는 사실은 올바른 Concept를 선택했다는 뜻이 아니다. 정답 라벨이 없으므로 Concept 정확도·검색 적중률·근거 적절성·자연스러움은 계산하지 않았다.

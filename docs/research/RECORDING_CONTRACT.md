# 연구 기록 계약

`schemas/`는 v3 연구 기록의 초안 계약이며 실행 KG의 최종 표현이 아니다. `experiments/templates/`는 미실행 예시로 수치와 성과를 포함하지 않는다.

지식은 안정적인 ID, 형태와 용법, 함수·조건·구성·범위, 근거 위치와 원문/해석 구별, 사용 상태, 검토 한계를 기록한다. 인용 문자열 존재와 의미 함의는 다른 검사다. 기존 ID를 가져올 때 원본 저장소·커밋·경로·ID를 함께 보존한다.

실험은 고유 run_id, status, 독립 평가 여부, 입력 단위·조건·공유 분석, 코드/KG/모델/요청·응답 식별자, seed·샘플링, 신규·재사용·실패·재시도·보존수정 호출 수, 평가와 한계를 남긴다. 기록이 없으면 unknown/null로 남기며 임의로 값을 채우지 않는다.

실제 실행은 `experiments/runs/<UTC timestamp>_<name>/`에 저장한다. private 데이터는 그 하위 `private/` 또는 local/에 두고 Git에서 제외한다. 커밋할 요약과 해시 목록이 민감한 내용을 노출하지 않는지 확인한다. 파일 해시는 재현의 식별자이지 정답 검증이 아니다.

결정은 문제·근거·대안·선택·결정 상태·변경·검증·반례·다음 단계로 기록한다. 제안을 수정 원본에 자동 반영하지 않는다. 실패는 삭제하지 않고 후속 해결과 연결한다. 덮어쓰기 대신 새 실행을 만들며 기준선을 재사용했으면 원래 run_id·요청해시를 명시한다.

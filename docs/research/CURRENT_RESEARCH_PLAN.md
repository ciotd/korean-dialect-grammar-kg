## 2026-11-07 우선순위 교정과 전수 검증 착수

사용자는 협업 분담과 다양한 비교 실험에 앞서 **①본인이 현재 연구의 핵심·실제 KG·최초 공통 문법 틀·속성을 정확히 설명할 수 있도록 이해 ②목표한 KG가 제대로 구축됐는지 모든 항목과 문장 실행을 연결해 전수 검증**하는 것을 우선으로 정했다. 예문이100개·1,000개 이상이 되거나 토큰·시간이 많이 들어도 비용 절약을 이유로 이 범위를 먼저 줄이지 않는다. 동료와의 연구 방향·가설·변인 통제 논의는 그동안 병행한다. 이 순서가 앞 절의 병행 기능 구현 권고보다 우선한다.

[현재 KG 이해와 전수 검사 착수 기록](../../experiments/analyses/kg_understanding_audit_20261107/README.md)에 실제 구조 설명과 모든 ID 대장, 속성 사전,57분기 명세를 기록했다. 원본/후보를 각각 집계한 노드3,945행·관계13,643행이며 버전별 중복을 포함한다. 합성 조건을 직접 입력한990건의 조회 계약 검사는 저장 논리와 일치했으나 자연어 예문·독립 의미 검증이 아니다. 새 예문0건·모델 호출0회다. 실제 예문 생성·전체 처리·원문 의미 대조·사람 판정은 이후 작업으로 남는다.

모든 그래프 항목을 목록에서 빠짐없이 추적하되, 실행 조건·문헌 내용·설계·출처·관리의 역할에 맞게 확인한다. 현재 조회가 사용하지 않는 관계는 예문 수만 늘려 실행됐다고 주장하지 않고 연결 공백으로 기록한다. 전체 대장 작성과 전체 지식 타당성 검증을 구별한다. 사용자의 전수 검증 요구를 일부 용법의 시연으로 대체하지 않는다.

검증·개발 과정의 오류는 근거와 새 버전으로 수정한다. 동료와의 방법 비교 전에 KG·분석·조회·전달·생성·입력·평가를 동결하고 사전에 정한 비교 요인만 바꾼다. 비교 중 결함 수정이 필요하면 원 실행을 보존하고 새 버전에서 영향받는 대조 조건을 다시 맞춘다. 수정 전후를 하나의 비교 조건으로 섞지 않는다. 새 연구의 모델 실행은 과거200호출 제한 프로그램과 구별해 등록하며 고유 입력·기대 조건·판정과 종료 기준을 먼저 기록한다.

## 2026-11-07 사용자 확정: 실행 지식과 출처·검토 기록 분리

사용자는 **“불필요한 설명·중복 주석은 제거하고, 출처·검토 기록은 실행 그래프 밖으로 분리”**하는 방향을 확정했다. 이후 KG 정제·조회·전달 설계의 공통 원칙으로 적용한다. 이번 기록은 방침 확정이며 실제 KG 이관·속성 삭제·전달 코드 변경을 완료한 것이 아니다. 앞선 현재 KG 이해·전수 검증 우선순위는 유지한다.

| 구분 | 보관하거나 전달할 내용 |
|---|---|
| 실행 문법 그래프 | 적용 대상·조건, 표현 후보와 결합 방법, 보존할 뜻·시제·높임 등, 필요한 문법 관계와 실제 예외·충돌 조건 |
| 별도 근거·검토 기록 | 문헌·위치·근거 발췌, 원문과 해석 구별, 검토·사용자 승인·변경 이력. 규칙/지식 ID와 버전으로 실행 지식에 대응 |
| 기본 Qwen 생성 요청 | 해당 문장의 대상 위치, 필요한 표현·결합 지시·보존 정보. 출처 위치·검토 이력·중복 관리 설명은 기본 전달에서 제외 |

분리는 근거 삭제나 조건 완화가 아니다. 방어적 설명·중복 주석은 제거하지만, 설명에 들어 있던 실제 문법 제약·미확정 조건·적용 예외는 명시적인 조건/관계로 옮긴다. 근거 확인이 필요할 때 별도 기록을 열 수 있어야 하며, 문헌 근거가 없는 추론·사용자 승인 내용을 문헌 사실로 바꾸어 표시하지 않는다. 지식의 적용 가능 여부에 필요한 판단값과 그 판단을 내린 검토 이력도 구분한다.

구현 시에는 기존 원본·실행 기록을 보존하고 새 버전으로 분리한다. 이관 전후의 규칙/지식 ID 대응, 조건·표현·문법 관계의 누락 여부, 별도 근거 기록의 참조 무결성, 실제 Qwen 요청의 제외 항목을 검사한다. 동일 입력의 조건 판정이 달라지면 단순 관리 정보 분리로 처리하지 않고 원인을 확인한다. 토큰 절감과 생성 품질 변화는 실제 측정 전까지 주장하지 않는다. 새 검토자 호출·모델 실험은 이번 방침 기록에서 수행하지 않는다.

## 2026-11-07 실제 분석과 KG 조건의 연결 점검

새 KG의 저장 동등성 검사 다음으로, 기존 실제 Qwen 분석 99기록과 회귀50문장의 90개 점검 지점을 대조했다. 규칙56개 전체에 새 점검 문장57개를 준비했으나, 새 Qwen 호출은 연결 실패로 실행하지 않았다. 진단 기록은 `experiments/analyses/semantic_reachability_20261107/README.md`와 `report_latest.json`에서 찾는다.

같은 프롬프트 수정과 50건 확대는 현재 멈춘다. 권고는 Kiwi 형태 분석 + Qwen 의미 판단·최종 문장 생성이며 기본 전환은 아직 하지 않았다. 다음은 동일 의미·작성 조건에서 형태 분석만 바꾸는 비교, 이어 의미 미확정과 KG 목표형 전달의 기여 확인이다. 자동 재작성은 품질 장치로 채택하지 않고 진단 후보로 남긴다. 두 검토자의 합의는 품질 인증이 아니며, 모델 사용 신고와 실제 적용도 분리한다. 전체 KG 정제·전수 검증·미지원 확장·논문 비교 과제는 계속 남는다.

#### 같은 날 후속: 형태 공급자 통제 비교 완료

[형태 공급자 비교](../../experiments/analyses/morphology_control_20261107/README.md)는 공통 원문 위치·이전 최초 Qwen 절 구획을 고정하고, 형태소 기본형/품사 공급자만 Qwen과 Kiwi로 바꿨다. 공통 observe_units 연결을 거쳐 같은 meaning/writer/reviewer 지시·모델·설정·KG를 사용했다. 자유문장 분석 설명은 후속 요청에서 제외했고, 자동 재분석·재작성은 양쪽0이었다. 기존 분업 대비 공통 연결 변화까지 Kiwi 효과로 해석하지 않는다.

실행 `20261107T074932735908Z_morphology_control_development`: 개발6쌍/12경로 완료·42호출·95,003토큰. Qwen형태 경로24호출/48,946토큰/188.04초, Kiwi18호출/46,057토큰/162.60초(각 경로 시간 합). 앞4문장의 최종 문자열은 같으나 요청문에서 본동사/보조용언으로 다른 규칙에 도달했다. 금지문은 Qwen형태 단위 누락과 Kiwi이후 의미/관계 오류가 구분됐다. Qwen의 셨/EP는 공통 연결에서 other/과거없음으로 계산돼 해예 규칙에 연결되지 않았다. Kiwi도 인사한 관형절 누락과 제→내 생성 오류가 남았다.

두 실제 Orca 검토자는 Kiwi를 다음 개발 기준 후보로 권고했으나 기본 전환은 미실행이다. 다음은 단위 누락과 미해석 선어말을 unknown으로 남기는 공통 계약, 금지/요청 및 본·보조 관계 판단, 복원 조사 규칙의 범위와 겸양 보존을 점검한다. 새로운 개발 문장에서 연결과 보존이 확인된 뒤50건 회귀로 간다. 자동 검토는 닫았나의 과거 손실을 허구로 지적했으므로 기본 재작성으로 채택하지 않는다. 사람 자연스러움·독립 정확도는 미평가이며 단회 개발 진단으로 제한한다. KG 문법 조건은 변경하지 않았다.

#### 같은 날 사용자 결정: Kiwi를 기본 형태 분석으로 전환

사용자가 형태 분석 통제 비교 후 Kiwi 기본 전환을 승인했다. 이 결정은 위의 Kiwi 제외·기본 미전환 기록보다 최신이다. `tools/run_qwen_multi.py`의 기본은 Kiwi이며, `--analysis-backend qwen` 비교 경로를 보존한다. 최종 문장은 계속 Qwen이 생성한다.

이번 묶음은 [Kiwi 기본 연결 보완](../../experiments/analyses/kiwi_default_20261107/README.md)이다. 누락/미확정 기록, 금지·요청 및 본·보조 연결, 겸양 보존을 보완한다. 새12개 개발 입력에서 짝 비교하고, 사전 기준을 통과할 때만50건 회귀를 실행한다. 한 차례 추가 보완 후에도 실패하면 같은 지시문 수정을 반복하지 않는다. 형태 분석 기본값 변경과 의미·생성 보완 후보의 품질 채택은 별개의 판단이다. 결과·채택 상태는 해당 폴더 RESULTS와 DECISIONS에서 확인한다.

실제 결과: 개발12문장 첫 비교84호출, 추가72호출 완료. 기능·본/보조 연결4/6→5/6→6/6이나 놓았어요→놓았어 높임 손실이 반복되어50건 진입 미충족. 두 Orca 검토자 모두50건 보류와 B2 후보 보존을 권고했다. Kiwi 기본은 유지하며 B1도 품질 검증 완료로 표시하지 않는다. 상세 결과와 다음 조건 역할/생성 분리 진단은 [RESULTS](../../experiments/analyses/kiwi_default_20261107/RESULTS.md). 추가 모델 호출은 종료하고 같은 지시 반복을 멈췄다.

## 2026-11-09 의미·관계 분업 설계 검토 — 미구현

사용자는 두 리뷰어 검토 후 설계안만 요청했다. 기존 Orca Claude·Codex가 독립 검토했고 [최종 제안과 의견 대조](../../experiments/analyses/semantic_workers_design_20261109/README.md)에 남겼다. 단일 질문 정리 대조군을 먼저 준비하고, 관계·역할→서술 표현 의미의2담당 분업을 비교 후보로 둔다. 절 구획 포함 분석 Qwen3역할, 작성·진단 포함 기본5호출이다. 세부 경계는 두 검토자가 완전히 동일하게 권고한 것이 아니라 리드의 종합 판단이다.

현재 의미·관계 담당은 여전히1명이다. Kiwi 기본, KG, 생성 코드와 실험 결과를 변경하지 않았고 새 Qwen 실험도 하지 않았다. 이 설계 문단은 구현 지시나 기본값 변경을 뜻하지 않는다. 생성자가 이미 전달된 높임을 무시한 문제와 불필요 KG조건 문제를 분업의 효과로 혼동하지 않는다. 다음 구현·비교는 설계와 최초 범위/종료기준 확정 후 수행한다.


## 2026-11-09 사용자 요청: 최근 구현으로 전체50 회귀 실행

사용자가 전체50 재실행을 명시하여 개발 진입 보류와 구분되는 진단 실행을 수행했다. [결과와 종료 판단](../../experiments/analyses/kiwi_focused_full50_20261109/RESULTS.md): 기존 kiwi_focused 코드·KG·프롬프트·모델 설정을 고정하고 절 분석부터 새로 호출했다. 50건 모두 시도, 전체 처리48건(변경39/동일9), 절 범위 실패1건·작성 초안의 사용 신고 불일치1건. 196호출·623,910토큰·37.35분. 품질 채택이나 독립 평가가 아니다.

최근 의미 분업 설계는 여전히 미구현이며 이번 실행에 섞지 않았다. 잘못된 말투 분석 때문에 조건을 놓친 경우, 규칙을 전달하고도 거절한 경우, 과거·높임 보존 정보를 받고도 출력에서 잃은 경우를 구분했다. 최종48건은 서버 원시 작성 문장과 동일하다. 상세화면은 승인 참조와 실제 출력 및 조회·전달 기록을 연결한다. 새 외부 Reviewer 평가는 수행하지 않았다. 이후에는 분석과 생성의 서로 다른 실패를 분리해 비교하고, 규칙의 결합 설명에 남은 예전 실행 담당 문구도 점검한다. 이번 결과만으로 기본 품질 버전을 승격하거나 자동 수정하지 않는다.


## 2026-11-09 50문장 오류 독립 검토와 공유 — 설계만

최신 50건을 기존 Orca Claude·Codex가 검토했고 리드가 원시 기록·수치를 재대조했다. 분석 조건 오분류/잘못된 규칙 전달, 경고에 의한 후보 차단, 전달 후 과거·높임 손실, 신고 형식 실패를 분리했다. 다음 제안은 공통 질문·차단·전달 약속 정리 후 분석 분업과 생성 분업의 독립 비교다. unknown 일괄 허용·문장 전체를 주절로 확정·표지 검사로 의미 보존 인증은 채택하지 않는다. 연구 코드·KG·새 Qwen 실행은 변경하지 않았다. 상세는 experiments/analyses/full50_error_design_20261109/DESIGN.md. 승인된 50문장 보고서를 Sites 공개 링크 사본으로 게시했으며 연구 실행 원본은 보존한다.

## 2026-11-09 현재 상태 정리 완료 — 다음은 전체 KG 목록·구조 검사

사용자는 사이드 채팅 계획과의 비교 후 **① 현재 상태 정리**를 지정했다. [현황과 다음 검사](../../experiments/analyses/current_state_20261109/README.md)에 실제 흐름·변경 이력·12모듈/26묶음 상태·실패 위치를 통합하고 기존 Orca Claude·Codex의 독립 검토를 반영했다. KG/실행 코드 변경과 새 Qwen 호출은 없었다. 현재 파일 KG는1,491노드/5,037관계,56조건 조회 규칙/57분기이고 최근 실행과 해시가 같다. 실행 코드12파일도 당시와 같다.

중요한 경계: 721참고 항목은 검색·기록되지만 최근 작성 요청에는 포함되지 않았다. 출처 전용 자료 분리는 완료됐으나 규칙 설명의 쪽수·검토 메모가 일부 작성 요청에 남아 있다. 현재 Kiwi 경로는 Qwen4역할이며 의미·관계 내부 추가 분업은 미구현이다. 별도 계획 옵션은 옛 Qwen 형태 경로에만 있고 Kiwi 기본에서는 거절된다. 최근50의 kiwi_focused 후보를 기본 품질 버전으로 승격하지 않았다.

합의한 세부 진행은 **①현재 상태 → ②전체 목록·구조, 조건별 예문, 규칙 조합 점검 → ③같은 분석·지식을 고정한 생성 방식 비교 → ④전체 연결 재검증**이다. 이는 상위 연구 순서의 진단/비교를 구체화한 것이며, 미지원 확장·KG 효과의 공정한 비교·독립 사람 평가를 삭제하지 않는다. ②에서 공통 질문·차단·전달의 불일치도 함께 확인한다. 이번에는②를 실행하지 않았다.

다음 범위: 모든 항목의 역할·연결·참조 상태표를 만들고, 기존12+추가44의 모듈/묶음 연결을 통합한다. 직접 모듈 연결 없는6규칙, 혼합 설명문, 최근 조건 통과 미관찰30규칙, 분석에 필요한 특징 칸을 확인 대상으로 둔다. 30규칙이 고장이라고 단정하지 않는다. 상태·미확인 이유·다음 조치가 추적되면 목록 검사를 종료하고 조건별 적용/비적용/미확정 예문 검사로 넘긴다. 지식 부족·충돌은 근거와 수정안으로 남기며 자동으로 지식을 확정하지 않는다.

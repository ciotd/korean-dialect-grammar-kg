# KG v3 연구 이관 문서

작성일: 2026-10-13 KST. 대상: `ciotd/korean-dialect-grammar-kg`. 원본: `ciotd/odor-complaint-dialect-rag`의 `main` 커밋 `0422b027ee92aaf461c29244987d4d8d2e094284`.

## 1. 연구 결론과 이관 범위

경상도 방언 문법을 형태·기능·용법·결합·근거의 그래프로 표현하고, 입력 문장에 필요한 지식을 제공하여 의미와 높임을 유지하는 자연스러운 방언 생성을 검증하는 연구다. KG는 검증 대상인 방법 가설이다. 기존 결과는 지식 연결과 국소적 생성 개선을 보여주지만 **KG의 전반적 품질 우위, 그래프 관계의 독립 효과, 수정 단계마다 품질이 상승한다는 주장**을 입증하지 못했다.

이번 이관은 기존 저장소를 수정하지 않는 연구 분리다. v3는 아직 새 KG·조회기·생성기 구현이나 새 실험 결과를 갖지 않는다. 기존 결과를 v3 성능으로 기재하지 않는다. 새 저장소 이름에 한국어 방언을 사용했지만 현재 근거 범위는 경상도다. 다른 방언으로 확장하려면 별도 자료·설계·평가가 필요하다.

근거 범위는 접근 가능한 GitHub의 기본 브랜치 파일·94개 커밋과 보존된 연구 문서·실험 기록이다. 커밋 목록은 초기 커밋까지 연결되며 현재 트리는 재귀 조회에서 잘리지 않았다. 파일별 원본 경로·Git blob SHA·고정 링크는 [원본 파일 목록](../provenance/source_file_inventory.tsv), 커밋은 [연구 커밋 이력](../provenance/commit_history.tsv), 문서 목록은 [근거 안내](../provenance/EVIDENCE_INDEX.md)에 있다. 모든 개별 모델 원응답에 독립적인 언어학 채점을 새로 실시한 것은 아니다. 원문 PDF·Git 제외 데이터·로컬 미커밋 상태·외부 대화 전문은 GitHub 기록만으로 복원할 수 없다. ‘모든 연구 이력’은 이 접근 범위 안에서의 종합과 추적 가능한 목록을 뜻한다.

기존 문서 안의 사용자 승인·중단 지시는 당시 연구 이력이다. 새 작업의 권한으로 자동 승계하지 않는다. 이번에 승인된 작업은 분석·이관 문서·새 저장소 초기 등록이며 모델 호출, 외부 평가 자동화, 원본 수정은 포함하지 않는다.

### 4.2 대표성과 독립성

조현준 자료는 2018년에 출간됐지만 근거 채록은 1978–1984년 경북 구술 자료이고 제보자는 대체로 고령층이다. 이를 2026년 경북 40대 이상 전체의 자연스러움 정답으로 쓰지 않는다. 함양 자료의 지역·조사 단계와 표준어 간섭 맥락도 보존한다. 위키 네 파일은 재인용·공유 계통이 있어 독립 증거 네 개로 세지 않는다. 동일 철자·공통 지역 표기·문헌 간 다수결만으로 용법을 병합하지 않는다. [자료 검토](https://github.com/ciotd/odor-complaint-dialect-rag/blob/0422b027ee92aaf461c29244987d4d8d2e094284/current_kg/docs/history/SOURCE_REVIEW_2026-09-07.md), [통합 검토](https://github.com/ciotd/odor-complaint-dialect-rag/blob/0422b027ee92aaf461c29244987d4d8d2e094284/current_kg/docs/history/KG_FEASIBILITY_2026-09-09.md)

AI-Hub는 독립 평가 후보이며 문법 근거와 혼합하지 않는다. 별도 어휘 JSON은 후보 자원으로 남기고 무조건적 문자열 치환 사전으로 승격하지 않는다. 과거 문법 JSON·검수 문서·39규칙은 새 지식의 직접 근거를 대신하지 않는다. PDF·전체 추출 원문·AI-Hub 문장쌍·어휘 원본·인증정보는 새 저장소에 복사하지 않는다. 원본에 없는 PDF의 표·각주 의미를 이번 분석에서 직접 재확인했다고 주장하지 않는다.

## 5. 설계 결정과 변경 이유

### 5.1 문법 KG v1

문서별 Claim 목록에서 공통 범주 아래 **용법을 중심으로 형태·기능·구성·조건·예문·근거를 연결**하는 직접 작성 구조로 이동했다. 이전 류성기318건과 과거688건 집계·Claim/design_probe는 역사 상태이며 현행334기록과 합산하지 않는다. 영구 문법 KG와 입력 문장 분석 그래프를 구별하고, 공통 기능과 적용 자리로 연결했다. 단일 표면형은 공유할 수 있어도 비이다의 보이다/베이다, 카다의 지시/인용, 히의 사동/피동, 니의 인칭/수량 용법은 별개다.

v1에는 KnowledgeRecord, ExpressionUse, SurfaceForm, Assertion과 출처·조건 노드가 있다. `same_usage_candidate`는 동일성 후보, `shares_function_with`는 공통 기능, `scope_tension_with`는 검토할 범위 차이다. 어느 것도 자동 치환·조건 상속·확정 모순을 뜻하지 않는다. 결합 관계가 있어도 모든 연쇄 순서를 허용하지 않는다. 보류 관계와 근거 미확인 기록은 통합 경로에서 차단했다.

초기 기능 조회는 인용·어휘→활용 진입을 충분히 제공하지 못했다. 이후 문자·원문 검색, E5 혼합 검색, 입력 구간 결속, 조건·예외 판정, 관계 확장 경로를 통합했다. 10월 8일 최신 v1은 334기록·6,214노드·15,978관계, 문법 진술 1,156·통합 관계 149다. 이 숫자는 v2의 원자 진술 수와 동일 단위가 아니다.

E5 개발 모듈은 `intfloat/multilingual-e5-small` revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`, query/passage 접두어, 평균 풀링·정규화·내적을 사용했다. 384토큰/64중첩, 1,685조각, 상위50 RRF k=60은 당시 개발 설정이다. 방언 문법 검색 최적값으로 검증된 것은 아니다. 관계 확장은 실제 기록 노드에서 교차 관계를 따라가며 공통 기능 노드로 무제한 확장하지 않았다. Neo4j는 검사용 미러였고 실제 후보·조건 판정은 Python이었다.

원문 통합에서 제안한 교차 연결은 의문 기능↔서술부/선어말, 의문형↔요 결합/결과 높임, 완결↔보조용언/활용, 인용↔하다/카다 축약, 사동↔어휘 활용/명령 높임, 목적절↔구로, 관형절↔의존명사/계사/양태, 명사구↔조사/말음, 지시·제안↔참여자/명령 청유의9묶음이다. 일부 경로 확인은 전체 문법 연산 구현이 아니다. 니더/이더 설계 카드도 부르다·낫다의 의미/품사, 어간 말음, 어휘별 예외, 저자 분석과 관찰 형태를 분리한 국소 설계 대조다. 일반 규칙 전체의 독립 검증으로 확대하지 않는다.

### 5.2 문법 KG v2

v2는 기존 KG를 자동 변환하여 전수 검토를 대신하지 않고 별도 구축했다. 진술은 source/target pattern, 기능, 조건, 자연어 제약, 범위, 근거, 주장 상태, 사용 상태를 공통 규격으로 갖는다. 조건 소유자는 `input`, `candidate`, `target`, `context`로 나눴다. **먹다 입력에서 묵다 활용을 조회하면서 입력 자체가 묵다여야 한다고 요구하는 오류**를 피하기 위한 결정이다.

KnowledgeStatement와 출처별 ExpressionUse, Condition, Constraint, Function, Evidence, SourcePage, Source를 연결한다. `candidate_has_inflection`은 어휘 대응의 목표 기본형에서 활용 진술로 이동하지만 의미·지역 일치의 자동 보증은 아니다. `document_dependency`로 자료 계통을 남긴다. 모델 전달용 ‘카드’는 KG 노드 유형이 아니라 원본 ID를 추적하는 패킷이다.

`candidate`는 생성 승인과 다르고 `reference_only`·`blocked`는 직접 변환 참조와 구별한다. 조건값 미확보는 unknown이며 미기재를 ‘제약 없음’으로 바꾸지 않는다. 자유 의미 풀이를 정확 일치 조건으로 만들지 않는다. 표에서 관찰한 활용형을 다른 모든 어휘에 생산적인 규칙으로 일반화하지 않는다. [v2 작성 계약](https://github.com/ciotd/odor-complaint-dialect-rag/blob/0422b027ee92aaf461c29244987d4d8d2e094284/kg_v2/AUTHORING.md)

### 5.3 후속 분석과 생성 보완

Qwen 절 분석과 Kiwi 형태 분석을 결속하고, 서술어 기본형·선어말·문말 기능·원문 위치를 후보에 전달했다. 후속 오류에서 XSV/XSA 파생 서술어와 계세요 복원, 단순 기능 목록 후보의 제한, 관형절 보존, 높임·의도·인용별 후보 순위, 구간 계획과 최대1회 보존 재검토가 추가됐다.

문헌 확인형과 모델 조합형은 출처를 구별한다. 모델이 조합한 형태를 문헌에서 확인된 형태로 기록하지 않는다. 어휘 대응→활용→전체 문장 생성은 서로 다른 결정이다. 자연어 제약과 문맥 적합성은 완전히 계산되지 않았고 생성기가 적용 위치 밖을 바꾸는 문제가 남았다. 후속 70개는 원래 A/B/C/D의 재실행이 아니라 수정된 단일 경로의 전후 비교다. 의미 검색 B/D가 자동으로 생산 기본값에 채택된 것은 아니다.

## 6. 실험 결과와 해석 한계

### 6.1 초기 RAG v1의 결과

S1은 키워드→방언 대화 직접 생성, S2는 키워드→표준어 대화→방언 변환이다. C0 무주입, C1 고정 few-shot, C_kb 규칙·예문 주입/어휘 검색, C_kb+C1 결합을 비교했다. S1의 문법 공급은 고정 범주 주입이 지배하므로 전체를 질의 기반 retrieval 효과로 부르지 않는다.

Qwen3.8-27B-FP8로 통일한 n=100 기록의 어미 방언율은 S1 C0 .014 / C_kb .050 / C1 .084 / 결합 .085, S2 .048 / .060 / .199 / .112다. 이는 어미 표지 기반 기술값이며 전체 번역 정확도가 아니다. 어휘 활용률21.1%, 규칙 활용률10.6%, 어휘 무주입28/100이 기록됐다. 사전 기반 어휘 지표와 독립 AI-Hub 참조의 차이는 S2 C_kb−C1에서 +.0397 / −.0057 / +.0045로 방향도 달라 어휘 우위 주장은 견고하지 않았다.

Opus 블라인드 자연스러움 비교에서 C1>C0는 S1 97%, S2 89%; C_kb>C1는 S1 20%, S2 43%였다. S2의 43%는 50%와 유의차가 없는 기록이다(p≈.19). 교란 분별98.9%는 쉬운 관문 통과이며 미세한 자연스러움 평가의 충분조건이 아니다. S2 어미 지표 감소에는 어미 적중 변화와 정렬 분모 변화가 함께 작용했으며 당시 분석은 각각 약−29%, −30%로 분해했다. 이를 독립 개입으로 입증한 인과효과라고 기술하지 않는다.

전라·강원의 과거 문법 자원에 모델 생성 오염이 확인됐고, 해당 자원을 주입한 결과에는 자원 품질 교란이 있다. 자동 마커·judge·사람 검증을 동일시하지 않는다. 위 수치는 보존 문서의 결과이며 이번 이관에서 원데이터 재계산을 실행하지 않았다. [RAG 연구 범위와 결과](https://github.com/ciotd/odor-complaint-dialect-rag/blob/0422b027ee92aaf461c29244987d4d8d2e094284/archive/v1_retrieval/docs/research_scope.md)

### 6.2 8월 초기 v2 graph의 측정 실패

AI-Hub 일반35+의문25의 60쌍에서 마지막 음절 일치 기준 copy34/60, plain30/60, 덤프26/60, KG23/60이었다. 의문25개만 보면12/11/11이었다. 어미 변경 필요30개에서는 plain=KG=6으로 같았고 차이는 유지해야 할 입력의 과잉 변경에서 나타났다. 당시 KG oracle 상한12/60이 copy34/60보다 낮아 지표 목적 자체가 불일치했다.

주입 어미 복사16개는 해당 기준0/16, 비복사39개는19/39였다. 문말 어절을 제외하면 경상 마커는 세 조건 모두0/60이었다. 마커3→8을 anchoring 증거로 해석한 것은 주입 문자열의 재측정이며8개 중6개는 해당 정답 기준 오답이었다. STD_ENDING의 호환자모6키가 Kiwi 결합자모와 매칭되지 않는 버그, 질문 종류 정확도58.3%가 majority62.5%보다 낮은 문제도 확인됐다. 엔드포인트 장애로 당시 재실행이 불가능했다.

따라서 이 결과는 **KG 기여의 부호를 판단할 수 없는 측정 실패**다. KG가 일반적으로 나쁘다는 결론도 낼 수 없다. 규칙표 자원, 과잉 주입·평가 순환성·과잉 변환의 진단은 남는다. focused>덤프, anchoring, 조건부 KG novelty 주장은 철회된 기록으로 유지한다. ## 8. KG v3 초기 연구 계획

### 8.1 제안된 연구 질문

1. 같은 문헌 근거 풀에서 KG의 명시적 용법·조건·구성 관계가 텍스트 검색보다 적절한 근거 선택을 개선하는가?
2. 같은 후보를 제공할 때 원본 진술 전달과 검토된 구간 계획 전달이 후보 실현·의미·높임 보존에 어떤 차이를 만드는가?
3. 관계를 추가한 비교에서 실제로 다른 근거를 받는 입력이 충분한가? 차이가 없다면 해당 대비가 식별하는 효과는 무엇인가?
4. 최소한의 올바른 근거와 형태 계획을 제공해도 생성 오류가 남는가? 분석·조회·생성 병목을 분리할 수 있는가?

위 질문은 제안이며 KG 효과가 양수라고 전제하지 않는다. 구축 정책 비교와 생성 전달 방식 비교는 서로 다른 실험이다. 같은 원문·작성 예산·평가 단위가 없는 기록 수 비교는 구축 성능 실험이 아니다.

### 8.2 첫 단계의 우선순위와 종료 기준

**P0 재현과 근거 경계:** 기존 v2를 고정 링크로 참조하고 로컬 PDF 접근·라이선스·해시를 확인한다. 문헌 확인형, 원문 일반화, 작성자 해석, 조합 제안, 부정 예문을 구분한다. 완료 기준은 작은 실제 대상 묶음에서 원문 위치·용법·조건·범위·반례가 추적되는 것이며 페이지 읽기 수만으로 완료하지 않는다.

**P1 병목 진단:** 제공 후보 미적용, 목록 후보 오용, 인용/의도 조합, 관형절, 겸양·청자높임, 조건 unknown을 포함한 층별 진단 세트를 만든다. DEV025/NEW007/DEV027/LONG006은 과거 회귀 사례다. 새 독립 평가에는 재사용하지 않는다. 각 오류를 문헌 부족·KG 표현·분석·조회·계획·생성·검사 누락으로 중복 분류하고 인과 확정 여부를 표시한다.

**P2 표현·계획 검토:** 적용 대상 구간, 어휘 의미, 결합 자리/순서, 문헌 범위, AND/OR/예외 및 미확인 조건 처리를 제안하고 반례로 대조한다. 좁은 모델 조합형은 문헌 확인형으로 승격하지 않는다. 전체 재구축이나 데이터베이스 전환부터 시작하지 않는다.

**P3 실험 동결:** [평가 계획](research/EVALUATION_PLAN.md)의 조건·표본·화자·지표·분모·불확실성 보고를 확정한 뒤 새 실험을 실행한다. 필요한 관계가 실제로 제거/추가되는지 요청 차이를 먼저 검사한다. 출력 차이만으로 개선율을 산출하지 않는다. 평가 결과를 보고 규격을 바꾸면 개발 단계로 되돌리고 새 평가 자료를 확보한다.

**P4 독립 평가와 논문:** 미사용 입력의 의미·높임·문법·방언 자연스러움, 근거 도달·적용 적합성을 분리해 블라인드 평가한다. 인용 추적·정제 비용·검색/생성 토큰·시간도 보고한다. 효과가 없거나 손상이 있으면 그대로 negative result로 남긴다.

### 8.3 운영 원칙과 초기 구조

새 저장소의 [AGENTS.md](../AGENTS.md)는 원본 쓰기 금지, 근거 기반 판단, 모델 제안과 사실 구별, 실패 보존, 불변 실행 폴더를 규정한다. [설계 결정 장부](research/DECISIONS.md)는 계승한 결정과 새 제안을 구별하고, [미해결 질문](research/OPEN_QUESTIONS.md)은 위험과 검증 방법을 기록한다. `schemas/`와 `experiments/templates/`는 기록 계약이며 기존 KG를 가져온 운영 스키마 또는 실행 모델 파이프라인이 아니다.

새 실행에는 고유 run_id와 UTC 실행시각 및 KST 표시를 기록한다. 원문·분석·조회·계획·전체 생성 요청·응답·모델 체크포인트·샘플링·코드/KG SHA·패킷 예산·재시도와 채택 기준을 보존한다. 원본은 덮어쓰지 않고 latest는 포인터만 바꾼다. 자연스러움 점수가 없으면 null로 남긴다. 실패·빈 후보·unknown·미수정 출력도 보존한다.

## 9. 재개 절차와 완료 상태

다음 연구자는 이 문서, 설계 결정 장부, 근거 목록을 읽고 **v3는 이관과 연구 구조만 완료**되었음을 확인한다. 현재 기준선은 원본 고정 SHA이며 새 저장소에 기존 PDF·KG 데이터·모델 서버 설정을 자동으로 복제하지 않았다. 원본의 실행 명령은 역사 자료이고 새 환경에 그대로 실행 가능한 것으로 보장하지 않는다.

먼저 기록 계약 검사를 실행하고 P0/P1의 제한된 실제 검토 범위를 정한다. 이후 별도 사용자 요청 또는 명확한 연구 범위에 따라 자료 접근·구현·실험을 진행한다. 이번 이관 완료를 문헌 전수 독립 검증, KG v3 구축 완료, 화자 평가 완료, API 자동 평가 가동으로 바꾸어 보고하지 않는다.

원본 저장소 보호의 핵심은 기존 저장소에 쓰기 호출을 하지 않는 것이다. 작업 전후 `main` SHA를 비교하는 것은 추가 확인이며 저장소의 모든 외부 변경 부재를 암호학적으로 증명하지는 않는다. 새 저장소 쓰기 대상은 `ciotd/korean-dialect-grammar-kg`로 한정한다.

## 역할과 모델

- Codex: GPT-6-Astra, reasoning High. 실험 설계·처리 코드·원인 분리·측정과 해석을 독립 검토한다. 코드 변경과 실험 실행은 총괄이 담당한다.
- Claude: Claude Opus 5 (`claude-opus-5`). 문법·지식 검토를 맡는다. 카드와 문장의 관계뿐 아니라 카드 자체의 오류·누락을 확인하고 외부 문헌·사전·방언 용례를 검색·열람하여 보완본을 작성할 수 있다.
- 모델 가용성이나 인증이 실패하면 다른 모델로 조용히 대체하지 않는다. 설정값과 실제 응답 모델을 구분해 기록한다.

## 공통 검토 결과

한국어로 작성하며 각 지적에 반드시 다음 세 항목을 넣는다.
1. 문제 위치: 카드 ID/필드, 함수·파일, 입력 ID·실행 시점 중 해당하는 것.
2. 실제 근거: 원문/실제 요청·응답/외부 출처와 위치. 관찰과 해석을 구분한다.
3. 수정안: 무엇을 어떻게 바꾸는지. 아직 원인이 불명확하면 그 원인을 구분할 확인 방법을 쓴다.

단순 '자연스럽지 않다'로 끝내지 않는다. 다른 가능한 원인과 수정 후 확인 방법도 필요하면 함께 적는다.
처음에는 독립 검토한다. 다른 검토자의 결론·총괄의 결론을 그대로 따라가지 않는다.
모델들의 동의나 다수결을 언어학적 사실의 인증으로 쓰지 않는다.

- Claude Code의 WebSearch, WebFetch와 로컬 Read 도구를 활용한다. 검색·열람은 이번 사용자 지시로 허용됐다.
- 원본 7문헌에 한정하지 않는다. 외부 논문·사전·실제 방언 용례도 확인할 수 있다.
- 외부 근거에는 제목/기관·저자/URL/쪽 또는 항목/열람일, 알 수 있는 지역·시기를 남긴다.
- 현재 목표는 사용자가 승인한 현대 경상도 표현이며 부산·경남도 포함한다. 엄격한 지역·세대 필터는 후속 연구다. 그러나 상충하는 용법은 합쳐 단일 규칙으로 만들지 말고 차이를 기록한다.

- 보완은 새 카드 버전 또는 변경안 파일로 작성하여 기존 카드·근거·실험 결과를 보존한다. 각 변경에 이전 값/변경 값/이유/근거를 남긴다.
- 활성 KG/기본 실행 카드로의 통합은 총괄이 구조·코드 검증 후 처리한다. 목표·스키마·평가 기준의 중요한 변경이나 충돌되는 실제 표현 판단은 사용자에게 보고한다.
- 과거 실험의 해시·결과를 수정하지 않는다. `ciotd/odor-complaint-dialect-rag` 원본 저장소는 계속 읽기 전용이다.
- 공개 자료 검색에 인증키나 비공개 실험 원본 전체를 질의로 넣지 않는다. 관련 문법 표현·현상을 검색한다.

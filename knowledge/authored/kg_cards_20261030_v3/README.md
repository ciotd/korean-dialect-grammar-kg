# 생성용 카드 내용 보완 · v3

전체 721개 ID를 유지한 새 생성용 카드 버전이다. 원본 KG 노드·관계와 v2 파일은 변경하지 않았다.

## 결과

- 573개 변경: 563개는 관리·출처 조건 분리, 10개는 변환 방향 안내도 추가.
- 148개는 내용 동일. 8개 핵심 카드의 입력 조건은 구체적으로 다시 적었고, 경쟁 후보 2개에는 오적용 방지 안내를 추가.
- 출처·지역/시기 정보는 `provenance.json`에 이전 위치·값과 함께 보존했다. 문법상 상대 관계·화계·받침·형태 제약을 일괄 삭제하지 않았다.
- 모든 forms 배열·순서·ID·module·kind·title·avoid는 v2와 같다. 721개 모두를 실행 가능한 변환 규칙으로 승격한 것은 아니다.

## 사용

기존 `tools/run_kg_cards.py` 실행 인자에 `--generation-card-version kg_cards_20261030_v3`를 추가한다. 이 실행은 Qwen 호출을 발생시키므로 실제 실험 범위를 정한 뒤 사용한다. 옵션이 없으면 기존 v2 실행이 유지된다.

기존 v2로 조회·순위를 계산한 후 선택된 ID와 순서 그대로 v3 내용만 전달한다. 새 내용으로 request_id를 다시 만들고 생성·검사에 같은 카드 배열을 사용한다. 검색 알고리즘·프롬프트·검사 코드는 이번에 변경하지 않았다. 새 자연어 조건은 모델용 안내이며 프로그램이 자동 집행하는 조건식이 아니다.

## 근거와 검토

문헌의 형태·용례, 사용자 승인 정답 50개, Codex가 작성한 재사용 조건을 구분했다. 사용자 승인은 50개 문장의 표현에 대한 것이며 새 카드 일반화 전체에 대한 승인이 아니다.

보조 검토자 2명이 읽기 전용으로 초안·수정안을 검토했다. 과거/부정 계사 누락, -께예 원인/약속 혼동, -라/-래 결합 구별, forms 번호 유지, 요청 식별값 재생성, 작성 주체 오표기 지적을 반영했다. 최종 리뷰 요약은 분석 폴더의 `private/reviewers.json`에 있다. 검토자 의견은 모델 생성 품질 검증을 대신하지 않는다.

## 검증

관련 자동 테스트 81개 통과. 기존 49개 문장과 카드 전달 비교 26개에 대해 실제 전달 목록의 ID·순서를 유지한 내용 투영 75개를 확인했다. 원래 분석 실패 1개는 보존했다. 시험용 계획 6개가 기존 검사·조립을 통과했으나 Qwen 출력이 아니다. 신규 모델 호출은 0회다.

한 편집 오류로 전체 계획이 실패하는 동작, 요를 조사/어미로 다르게 취급하는 문제, 새 문장 일반화는 후속 검증 범위다. 카드별 Python 변환 함수를 추가하지 않았다.

## 재생성

`tools/build_generation_cards.py --output knowledge/authored/kg_cards_20261030_v3 --source-cache <기존 source_audit 폴더>`를 사용한다. 원본 카드·승인 참조·문헌 추출 캐시와 spec이 필요하다. 같은 버전의 내용이 달라지면 덮어쓰기를 거부한다.

`cards.json`은 Qwen용, `provenance.json`은 이전 조건·출처·판단 근거, `changes.json`은 변경 ID 목록, `manifest.json`은 해시와 작성 방식, `statistics.json`은 실제 집계다.

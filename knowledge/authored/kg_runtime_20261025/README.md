# 검색/실행 분리 뷰

원본 `kg_v3_evidence_20261019_r2`의 1,625개 노드·6,167개 관계·12개 모듈을 동일 ID로 유지한다. 원본 Neo4j 데이터는 수정하지 않았다.

- `runtime.json`: 검색 가능한 개념/문헌 항목의 조건·동작·출력 및 17개 실행 연산자 연결.
- `provenance.json`: 동일 ID를 통한 출처·문헌 지역/시기·검토 상태 연결.
- `field_changes.json`: 원본 속성 중 실행 뷰에 남긴 것과 별도로 보존한 것.
- `statistics.json`: 실제 산출물 집계와 원본 해시.

721개 문헌 항목은 모두 검색 가능하다. 이것을 721개 문법 치환 연산자의 구현 완료로 읽으면 안 된다. 검색에는 과거의 활성화/프로필 승인 차단을 적용하지 않으며, 문장 수정에는 명시적인 입력 조건과 연산자가 필요하다.

재생성 명령: `python tools/build_kg_runtime.py --search-projection`. 기존 버전을 덮어쓰지 않으므로 이미 존재하면 중단한다. 상세 설계는 `docs/research/SEARCH_EXECUTION_20261025.md`에 있다.

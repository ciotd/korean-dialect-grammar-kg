# 간결한 문법 카드 v2

원본 `kg_v3_evidence_20261019_r2`의 SourceAtom 721개, 공통 개념 125개, 문법 모듈 12개에서 만든 실행용 보기다. 원본 Neo4j ID를 그대로 사용한다. DB의 원본 속성을 덮어쓴 결과가 아니다.

| 파일 | 역할 |
|---|---|
| `cards.json` | 생성 모델에 선별해 전달할 문법 지식. ID·모듈·종류·제목·조건·형태·제약 |
| `provenance.json` | 같은 ID의 출처·기존 명세·검토 상태. 생성 입력과 분리 |
| `statistics.json` | 실제 항목 수, 같은 직렬화 방식으로 계산한 정보량, 원본 해시 |

`when`은 문법 조건을 설명하는 데이터다. 현재 실행에서는 Qwen이 의미를 해석한다. 모든 조건을 자동으로 참/거짓 판정하는 완성된 규칙 엔진은 아니다. `kind`는 설계 규칙·형태 목록·관찰·분류를 구분한다. 검색 가능하다는 이유로 이들을 모두 동일한 치환 명령으로 간주하지 않는다.

생성기는 원본 ID의 실제 그래프 경로를 조회한 뒤, 최대 48개 카드를 선별한다. 17개 Python 변환 목록을 사용하지 않는다. 문헌별 어휘·형태 조건은 유지하되 지역·시기 운영 필터를 강제하지 않는다. 출처의 범위는 provenance에 남아 있다.

v1에서 놓친 점 표기 `target_register.mapping_status`, `target_register.profile_id`도 v2에서는 생성용 정보에서 제거했다. 말높임 조건인 `target_register.level_id`는 유지한다. v1과 중단된 실험은 과거 기록으로 보존한다.

생성 코드: `src/kg_runtime/cards.py`. 실제 분석·계획·활용 및 재현 방법은 [설계 문서](../../../docs/research/GRAMMAR_CARDS_20261028.md)를 참고한다. 카드 수정은 새 버전 디렉터리로 생성한다.

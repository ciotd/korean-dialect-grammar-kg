# 공통 문법 KG — 조건 근거 역할 보완 r4

`private/graph.json`: 146노드, 306관계. r2와 실행 조건·용법·실현형은 같다. r3에서 조건의 해석과 구현 선택을 분리했고, r4에서는 검토 의견에 따라 인용 문맥과 근거 역할을 보완했다.

- `INTERPRETS_SOURCE`: 문헌을 현재 조건으로 해석한 연결. 문헌이 모델의 라벨을 직접 정의했다는 뜻이 아니다.
- `DEFINED_BY_DECISION`: 분석기 대응 또는 현재 실험 범위를 정한 이유.
- `PRESERVATION_SUPPORTED_BY`: 높임 범주 보존의 문헌 근거.
- `PRESERVATION_LIMITED_BY`: 상황별 높임 정도까지 같다고 단정할 수 없는 근거.
- `EVIDENCE_ROLE`: 기존 의문 용례·의문법 장을 평서 규칙에 참고할 때의 한정된 역할.

선어말 4종 지원은 문헌의 완전한 허용목록이 아니다. 감탄 용례는 감탄사를 포함한 인용으로 연결했다. 해요→해예는 비격식 높임 범주 대응이며 동일한 사회적 높임 정도를 보장하지 않는다.

`private/change_ledger.json`: r3 대비 변경과 이유.
`private/fixed_analysis_replay.json`: 실제62개 Qwen 답변에 대해 출처 수정 전후 후보·준비상태가 동일한지 확인. 새 Qwen 호출과 자연스러움 평가는 없다.

원본 PDF·정확한 인용·실험 문장을 포함하는 private 데이터는 Git에 올리지 않는다. 원본 자료를 임의로 복제한 공개 패키지가 아니다. Neo4j 재적재는 수행하지 않았다.

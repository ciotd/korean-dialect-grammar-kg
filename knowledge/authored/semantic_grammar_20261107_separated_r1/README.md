# 문법 지식과 출처 기록을 분리한 KG — 2026년 11월 7일

문장 조회에 쓰는 통합 KG를 실제로 분리했다. 이전 통합본은 그대로 보존한다. 새 문법을 추가하거나 적용 조건을 완화한 버전은 아니다.

## 두 파일의 역할

| 파일 | 담긴 내용 | 읽는 주체 |
|---|---|---|
| `private/<고유 시각>/graph.json` | 문법 지식·조건·표현·의미 보존 정보·문법 관계. 미정제 지식도 검색용으로 유지 | 기존 `IntegratedReader`, Qwen 전달 내용 구성 코드 |
| `private/<고유 시각>/audit.json` | 출처·발췌·쪽수·검토 기록과 변경 전 속성. 이전 그래프 전체를 복원할 수 있는 기록 | 연구자/검토자가 요청할 때만 별도로 조회 |
| `private/<고유 시각>/manifest.json` | 원본·실행 그래프·기록 파일·코드·재생 자료의 해시와 검사 결과 | 재현·무결성 확인 |
| `latest.json` | 검사에 통과한 새 저장 버전의 실제 경로 | 통합 실행기의 기본 경로 선택 |

같은 규칙/지식 ID와 버전으로 두 파일을 연결한다. 출처 파일을 Qwen 요청에 넣지 않는다. 실제 실행 시에는 출처 파일도 비공개 실행 기록에 보관하여 나중에 근거를 재확인할 수 있다.

현재 통합본 2,320개 노드·7,476개 관계에서 **1,491개 노드·5,037개 관계**를 실행 파일에 남겼다. 출처·검토 전용 노드 829개와 관련 관계 2,439개는 별도 보관했다. 문법 규칙 56개·조건 분기 57개·미정제 문헌 지식 721개·12개 모듈은 유지한다. 원본 문헌 KG 1,625개 노드·6,167개 관계를 덮어쓴 것이 아니다.

## 실행 및 출처 확인

`tools/run_integrated_grammar.py`에서 `--graph`를 생략하면 이 폴더의 `latest.json`을 따른다. 과거 비교 실험에서는 `--graph <과거 graph.json>`을 명시한다. 이번 작업에서 새 모델 호출은 하지 않았으며, 기존 실행기의 모델 호출 승인·예산·종료 조건도 바꾸지 않았다. 오래된 200회 제한 프로그램을 새 연구 범위로 전용하면 안 된다.

```powershell
# 출력 경로는 새 private 파일이어야 한다. 이미 존재하면 덮어쓰지 않는다.
python tools/inspect_separated_kg.py --node SEM_Q_V_WH --output experiments/analyses/kg_storage_separation_20261107/private/manual_lookup.json
python tools/inspect_separated_kg.py --restore --output experiments/analyses/kg_storage_separation_20261107/private/manual_restored.json
```

다시 정리할 필요가 생기면 `python tools/separate_kg_storage.py`로 새 고유 버전을 만든다. 이전 결과는 남고 최신 경로만 갱신된다. 조회기·분리 코드와 사전 고정한 990개 조건 사례, 기존 분석 기록을 사용한다. 실패하면 최신 경로는 갱신하지 않는다.

## 제거 기준과 한계

- 명시적으로 열거한 출처/검토 속성, 정확히 일치하는 관리 설명, 동일한 ID·제목·지시 중복만 분리/제거했다. 변경 위치를 전부 기록했다.
- 실제 적용 조건, 가능한 형태, 보존 사항, 부정·예외·지역 차이·미확정 상태를 함부로 삭제하지 않았다. 의미와 관리 설명이 섞여 있는 불명확한 문장은 그대로 남겼다. 모든 설명을 자동으로 완벽하게 다시 썼다는 뜻은 아니다.
- 모든 남은 속성의 변화가 기록된 변경 목록에 포함되는지, 모든 문법 관계의 ID·종류·양 끝 노드가 같은지 검사했다. 두 파일을 합치면 원본 JSON 전체가 일치한다. 원본 파일의 바이트 사본도 별도로 보존했다.
- 990개 조건 사례와 기존 분석 99개 기록/802개 위치를 재생했다. 조회·문법 전달 내용은 같고, 길이 제한에서 실제 전달 규칙 목록도 같았다. 참고 항목은 더 짧아져 2개 기록에서 더 전달되었다.
- 이것은 저장·전달 구조 검증이다. 문헌 해석의 정확성, 현대 방언 자연스러움, 토큰·속도 개선은 새로 검증하지 않았다. 과거 Neo4j DB도 변경하지 않았다.
